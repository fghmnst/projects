# Mission: 复刻视觉追踪火控云台，学会 STM32 嵌入式开发

## Why

30 天学习计划的主线。从零做出一个能实时追踪橙色球的二自由度云台（STM32F103C8T6 + 2×SG90 舵机 + OpenCV 视觉 + PID 控制），走通嵌入式开发全流程；为加入学校机器人队积累真实项目经验与调试能力。

## Success looks like

- 云台实时锁定橙色球，激光头稳定跟随、基本不脱靶（误差死区内）
- 能独立看懂并修改参考仓库全部代码（`main.c` / `ball_track.py` / `pid.py`），PID 调参不再靠盲试
- 完整走通工具链：CubeMX 生成 → vscode+CMake 编译 → ST-Link 烧录 → 串口观察，能自己排查环境问题
- 建立嵌入式调试方法论（分模块验证、串口打印、逐环节隔离），可迁移到下一个 STM32 项目

## Constraints

- 起点：会一点 C 与 Python（基础语法水平），**零 STM32/嵌入式经验**；已通读参考仓库源码一遍（读过≠掌握）
- 时间：30 天假期，深度日主线 5h；浅度日不碰硬核；每晚另有 C++ 副线（贪吃蛇课程）——主线课程不能假设晚上时间
- 硬件已齐：STM32F103C8T6、2×SG90 舵机、CH340、USB 摄像头、**ST-Link V2**（SWD 烧录）
- 工具链已定：vscode + STM32CubeMX + CMake；Python 仅作工具语言
- 课程用 markdown 编写（与贪吃蛇课程一致），位于 obsidian vault 内；每课一个可验证里程碑
- 知识沉淀：每日日志 + 术语表 + 模块笔记（vault 顶层目录已建）

## Out of scope

- 寄存器级裸机开发（HAL 优先，卡住时按需下钻）
- 电路设计/PCB 制作（面包板+杜邦线搭接）
- 云台支架的机械设计与 3D 打印（用现成支架）
- RTOS、DMA、中断嵌套等进阶主题（本项目的 GPIO/PWM/UART 用基础 HAL 即可）
- 云端 hermes/服务器（30 天计划二阶段内容）
