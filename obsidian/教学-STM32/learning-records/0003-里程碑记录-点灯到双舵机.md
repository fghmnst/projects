# 0003 · 里程碑记录：点灯 → PWM → 串口 → 双舵机（8/12–8/19）

> 2026-08-20 阶段回顾时补记（当时未建 learning record）。四个里程碑串联了主线从「工具链闭环」到「双舵机可控」的全过程。

## 里程碑链

| # | 日期 | 里程碑 | 验证方式 | 关键点 |
|---|---|---|---|---|
| 1 | 8/12 | **PC13 板载 LED 点灯**（0.5s 闪烁） | st-flash write + 目视 | 脉冲定位法锁定引脚；低电平点亮；Lesson 0001 闭环 |
| 2 | 8/14 | **PA0 外接 LED 点灯** | CubeProgrammer CLI 首用 + 目视 | 面包板供电体系（共地/回路）；坏灯珠排查；HAL 最小程序 |
| 3 | 8/18 | **TIM2 PWM 呼吸灯**（1kHz） | 编译通过（烧录待 8/19） | CubeMX 工作流恢复；PSC/ARR/Pulse 语义（计数值非百分比） |
| 4 | 8/19 | **双舵机 PWM + USART1 串口解析** | WASD 四方向全对 | 72MHz；TIM2 CH1/CH2 50Hz 舵机 PWM（PSC=71/ARR=19999/Pulse=1500）；`sscanf` 解析 `X增量,Y增量\n`；限位 500–2500 |

## 关键验证结论

- 烧录双通路可用：`st-flash`（1.8.0）与 `STM32_Programmer_CLI`（CLT 自带），日常走 VS Code F5（launch.json 已配 ST-Link GDB）
- 串口链路：PC → CH340（`/dev/ttyUSB0`）→ USART1(PA9/PA10) → TIM2 PWM 全通
- 方向翻转机制：`fire_control/servo_test.py` 的 FLIP_X/FLIP_Y（Y 舵机实测反向 → FLIP_Y=True）
- 已知限制：SG90 供电不足（18650 直连 3.7–4.2V < 4.8V 下限）→ Y 舵机力矩弱，待 5V 供电升级
