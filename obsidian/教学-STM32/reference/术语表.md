## 入门与工具链（Lesson 0001）

- **MCU（Microcontroller Unit，微控制器）**：芯片内集成 CPU+存储+外设的微型计算机。STM32F103C8T6：Cortex-M3 内核、64KB Flash、LQFP48 封装。
- **外设（peripheral）**：CPU 与存储之外的功能模块。GPIO=手，UART=嘴，定时器=节拍器。
- **寄存器（register）**：可读写的特殊存储单元，通过内存地址访问，硬件的最小操作单位（如 `GPIOA->ODR`）。
- **HAL 库（Hardware Abstraction Layer）**：ST 官方把寄存器操作封装成的 C 函数库，教学主线使用层。
- **时钟树（clock tree）**：时钟信号从晶振分给各模块的配置图。F103 经典配置：8MHz 晶振 × PLL9 = 72MHz。
- **PLL（Phase-Locked Loop，锁相环）**：时钟倍频器。
- **交叉编译（cross-compile）**：在本机（x86）编译出目标机器（ARM）架构的代码。
- **工具链（toolchain）**：源码到运行所需的整套工具：编译器+构建系统+烧录器+调试器。
- **EABI（Embedded Application Binary Interface）**：嵌入式平台的 ABI 约定，编译器/链接器/调试器配合的"接头暗号"。
- **构建系统（build system）**：组织编译规则（源文件/路径/链接脚本/宏）生成构建文件的系统，如 CMake。
- **烧录（flash）**：把编译产物 .bin/.elf 写入芯片 Flash。芯片上电从 Flash 起始地址 0x8000000 取指。
- **Flash**：芯片内非易失存储（64KB），存程序，掉电不丢。
- **RAM**：芯片内易失存储（20KB），存运行变量，掉电清空。
- **SWD（Serial Wire Debug）**：串行线调试协议，4 根线（SWDIO/SWCLK/GND/3.3V）连 ST-Link。
- **ST-Link V2**：ST 官方调试烧录器（USB 设备，VID 0483）。
- **驱动（driver）**：操作系统与硬件之间的翻译层。
- **vhci（Virtual Host Controller Interface）**：usbipd 在 Windows 侧创建的虚拟 USB 总线，设备经它共享给 WSL。
- **busid**：USB 设备端口标识（如 3-2），usbipd bind/attach 用。
- **代码生成（code generation）**：CubeMX 按 .ioc 配置自动生成初始化代码的过程。
- **USER CODE 区**：生成代码中 `USER CODE BEGIN/END` 之间的保护区，手写业务代码放这里，重新生成不被覆盖。
- **链接脚本（linker script，.ld）**：规定程序各段（代码/数据）在 Flash/RAM 的存放位置。
