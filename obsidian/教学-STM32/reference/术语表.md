## 入门与工具链（Lesson 0001）

- **MCU（Microcontroller Unit，微控制器）**：芯片内集成 CPU+存储+外设的微型计算机。STM32F103C8T6：Cortex-M3 内核、64KB Flash、LQFP48 封装。
- **外设（peripheral）**：CPU 与存储之外的功能模块。GPIO=手，UART=嘴，定时器=节拍器。
- **寄存器（register）**：可读写的特殊存储单元，通过内存地址访问，硬件的最小操作单位（如 `GPIOA->ODR`）。
- **HAL 库（Hardware Abstraction Layer）**：ST 官方把寄存器操作封装成的 C 函数库，教学主线使用层。
- **时钟树（clock tree）**：时钟信号从晶振分给各模块的配置图。F103 经典配置：8MHz 晶振 × PLL9 = 72MHz。
- **PLL（Phase-Locked Loop，锁相环）**：时钟倍频器。
- **交叉编译（cross-compile）**：在本机（x86）编译出目标机器（ARM）架构的代码。
- **工具链（toolchain）**：源码到运行所需的整套工具：编译器+构建系统+烧录器+调试器。
- **EABI（Embedded Application Binary Interface）**：嵌入式平台的 ABI 约定，编译器/链接器/调试器配合的"接头暗号"。
- **构建系统（build system）**：组织编译规则（源文件/路径/链接脚本/宏）生成构建文件的系统，如 CMake。
- **烧录（flash）**：把编译产物 .bin/.elf 写入芯片 Flash。芯片上电从 Flash 起始地址 0x8000000 取指。
- **Flash**：芯片内非易失存储（64KB），存程序，掉电不丢。
- **RAM**：芯片内易失存储（20KB），存运行变量，掉电清空。
- **SWD（Serial Wire Debug）**：串行线调试协议，4 根线（SWDIO/SWCLK/GND/3.3V）连 ST-Link。
- **ST-Link V2**：ST 官方调试烧录器（USB 设备，VID 0483）。
- **驱动（driver）**：操作系统与硬件之间的翻译层。
- **vhci（Virtual Host Controller Interface）**：usbipd 在 Windows 侧创建的虚拟 USB 总线，设备经它共享给 WSL。
- **busid**：USB 设备端口标识（如 3-2），usbipd bind/attach 用。
- **代码生成（code generation）**：CubeMX 按 .ioc 配置自动生成初始化代码的过程。
- **USER CODE 区**：生成代码中 `USER CODE BEGIN/END` 之间的保护区，手写业务代码放这里，重新生成不被覆盖。
- **链接脚本（linker script，.ld）**：规定程序各段（代码/数据）在 Flash/RAM 的存放位置。

## 工程结构解剖（Lesson 0002）

- **启动文件（startup file，.s）**：上电后执行的第一段汇编代码：设栈指针、建中断向量表、搬 .data、清 .bss、跳 main()。
- **中断向量表（vector table）**：「中断编号 → 处理函数地址」对照表，固定在 Flash 起始地址（0x08000000），硬件按表寻址跳转。
- **弱符号（weak symbol）**：可被同名强符号覆盖的定义。启动文件给所有中断提供死循环默认实现，用户定义同名函数即替换。
- **段（section）**：编译器把同类内容打包的集装箱：.text（代码）、.rodata（常量）、.data（有初值变量）、.bss（无初值变量）、.isr_vector（向量表）。
- **栈（stack）**：函数调用内存区（局部变量/返回地址），先进后出，编译器管理，从 RAM 顶向下生长。
- **堆（heap）**：malloc 动态分配区，程序员管理，裸机上由 `_sbrk()` 维护。
- **LMA / VMA（装载地址/运行地址）**：段初值存放处 / 段运行处。.data 初值存 Flash（LMA）、运行时在 RAM（VMA），启动文件负责搬运。
- **中断（interrupt）**：硬件打断 CPU 执行、跳去处理函数（ISR）再返回的机制。
- **ISR（Interrupt Service Routine）**：中断处理函数，应短小，不做耗时操作。
- **NVIC（Nested Vectored Interrupt Controller）**：Cortex-M3 的中断控制器，管优先级与嵌套。
- **SysTick**：内核自带 24 位倒计时定时器，HAL 配为 1ms 心跳，HAL_Delay/HAL_GetTick 依赖它。
- **推挽输出（push-pull output）**：GPIO 输出模式，可强驱动高低电平；控制 LED 常用。
- **上拉/下拉（pull-up/down）**：引脚悬空时用内部电阻固定电平，防止电平漂移。
- **HSI / HSE**：内部 8MHz RC 时钟（免晶振）/ 外部晶振时钟。F103 经典方案 HSE×PLL=72MHz。
- **时钟使能（clock enable）**：STM32 外设默认断电，用前须 `__HAL_RCC_XXX_CLK_ENABLE()` 开时钟，漏开则寄存器操作无效。
- **内存映射（memory map）**：Flash（0x08000000）/RAM（0x20000000）/外设寄存器（0x40000000）统一编址的地址表。
- **MSP（MCU Support Package）**：HAL 三段式之一，外设的引脚/时钟等板级配置，放 stm32f1xx_hal_msp.c。
- **AFIO**：F1 系列引脚复用开关，决定引脚当前归属哪个外设；SWJ_NOJTAG 可释放 JTAG 引脚。
- **编译宏（compile definition）**：全局 `#define`（USE_HAL_DRIVER / STM32F103xB），决定编译哪些代码分支。
- **include 路径**：`#include` 的头文件搜索目录清单。
- **Ninja**：高性能构建执行器，CMake 生成构建文件后由它执行编译。
- **preset（预设）**：CMake 预定义配置方案（Debug/Release），打包生成器/工具链/构建类型供一键选用。
- **_sbrk**：C 库 malloc 的底层内存分配钩子，裸机必须实现（sysmem.c）。
- **系统调用桩（syscall stub）**：C 库系统功能的裸机占位实现（_write/_read/_exit…），多数直接失败返回；printf 重定向在此改。
- **newlib（-nano）**：嵌入式精简 C 标准库，`--specs=nano.specs` 启用。
- **.elf / .bin / .map**：带调试信息的程序 / 纯二进制烧录文件 / 符号地址清单（排障用）。
- **CMSIS**：ARM 官方内核接口标准（core_cm3.h 内核寄存器 + stm32f103xb.h 芯片寄存器）。
- **Flash 等待周期（wait states）**：CPU 主频高时读 Flash 需插入的等待周期，SystemInit 自动配置。
