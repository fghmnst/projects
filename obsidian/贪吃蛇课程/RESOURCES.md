# C++ 贪吃蛇课程 Resources

## Knowledge（高质量一手资料）

- [cppreference.com: C++ 语言参考](https://en.cppreference.com/w/cpp/language)
  标准参考。查任何语法细节（类型、表达式、类、模板）以它为准。Use for: 课程中所有语法 claim 的核实。
- [cppreference.com: STL 容器](https://en.cppreference.com/w/cpp/container)
  vector / queue / string 等容器的权威文档（复杂度、成员函数）。Use for: 0002-0003 课容器讲解。
- [LearnCpp.com](https://www.learncpp.com/)
  免费系统的 C++ 教程，按主题分章节，讲法贴近初学者。Use for: 用户需要课外补充阅读时按章节指路。
- [learnxinyminutes: C++](https://learnxinyminutes.com/docs/c++/)
  一页速览 C++ 全语法。Use for: 复习与查漏，与我们的速查表互为印证。
- [g++ 手册（GCC 文档）](https://gcc.gnu.org/onlinedocs/gcc-13.3.0/gcc/)
  编译器选项权威来源。Use for: 0001 课编译命令的核实（-Wall、-std 等）。
