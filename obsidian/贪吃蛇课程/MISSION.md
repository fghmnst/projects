# Mission: 以终端贪吃蛇为载体学会 C++ 语言

## Why

30 天学习计划的副线。主线（视觉追踪火控云台）用的是 C(HAL) 和 Python，但用户想真正掌握 C++——尤其是 C 没有的部分（引用、类、STL）。终端贪吃蛇是一个完整、可玩、每步可见效果的项目，用它当载体，学完的语言能力可以直接迁移到后续任何 C++ 工程。

## Success looks like

- 不靠 AI 逐行代写，独立完成一个可玩的终端贪吃蛇（方向键控制、吃食物长大、撞墙/撞身 Game Over）
- 能用自己的话解释：引用 `&` 和指针的区别、`class` 封装、`vector`/`queue` 为什么比 C 数组/手写结构体好
- 课程结束后能读懂并小幅修改其他 C++ 小项目（如 STM32 的 C++ 工程、开源工具源码）

## Constraints

- 起点：会一点 C（变量/循环/函数/数组/指针都懂），未碰过 C++ 的类与 STL
- 每晚副线时间学习（深度日晚上），白天主线优先
- 运行环境：终端字符版，零第三方依赖
- 课程全部用 markdown 编写，位于 obsidian vault 内（本目录）
- 教学重点：C++ 语言本身（语法、类、STL），贪吃蛇是载体而非目标
- 工具链：g++ 13.3 + make（已确认可用）；后期纳入 CMake（需安装，0011 课前装）
- 课程路线见 [[课程路线.md]]：11 课，0008 为 Makefile 课，0011 为 CMake 加餐课

## Out of scope

- 图形库（SDL/raylib 等）与 GUI
- 网络/多线程/系统编程深入
- 模板元编程、智能指针等中高级主题（留到后续独立课程）
- 主线 STM32 的 C++ 化改造（与本课程无关）
