# C++ 贪吃蛇课程路线

> 每课一个可运行里程碑 · 每课约 30-60 分钟 · 难度逐步爬升（ZPD）
> 主线：C++ 语言本身；构建工具（Makefile/CMake）在语言成型后插入，作为主线 STM32 CMake 工程的预演

## 课程总览（11 课）

| # | 课程 | 里程碑 | 新学内容 |
|---|---|---|---|
| 0001 | 工具链与第一个程序 | 终端打印 Hello Snake | g++ 编译、`std::cout`、命名空间 `std` |
| 0002 | 终端渲染与 vector | 画出游戏网格 | `std::string`、`std::vector`（对比 C 数组） |
| 0003 | 蛇的数据结构 | 蛇身=坐标队列 | `std::queue`（对比手写结构体） |
| 0004 | 移动逻辑与引用 | 蛇能动起来 | **引用 `&`**（对比指针）、传参三种方式 |
| 0005 | 键盘输入与游戏循环 | 方向键可控蛇 | 游戏循环、状态机、termios 输入 |
| 0006 | 食物与碰撞 | 吃食物长大、撞墙 Game Over | `<random>`、函数重载初见 |
| 0007 | 面向对象重构 | 代码升级为 `class Snake`（拆成 .h/.cpp） | 类、封装、private/public |
| 0008 | **Makefile** | `make` 一键构建多文件 | 规则/目标/依赖/变量、增量编译 |
| 0009 | 对象的生命周期 | 重构后工程化收尾 | 构造/析构、`new/delete` vs 栈对象 |
| 0010 | 收尾与复习 | 完整可玩版本 + 速查表 | `const`、STL 选型对比、回顾 |
| 0011 | **CMake 加餐** | 贪吃蛇改用 CMake 构建 | CMakeLists.txt、与主线 CubeMX+CMake 工程衔接 |

## 构建工具设计逻辑

- **0001-0007 不用任何构建工具**：单文件/少文件阶段，`g++ -Wall x.cpp -o x` 一条命令足够，工具不干扰语言学习
- **0008 上 Makefile**：0007 拆成 `main.cpp + snake.cpp + snake.h` 后，手动编译命令变长、易漏参数——Makefile 恰好解决「多文件编译」这一个真实痛点，规则透明、原理可见
- **0011 上 CMake**：先体验 Makefile（知道构建工具在解决什么），再学 CMake 如何更进一步（跨平台、依赖管理、主线 CubeMX 正是用它）——三步各解决一个真实痛点，不凭空学工具
