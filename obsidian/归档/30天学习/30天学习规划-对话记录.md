## 三、参考项目技术栈（知乎文章原文要点）

- **硬件清单**（成本 <30 元）：
  - 主控 STM32F103C8T6（15 元）
  - SG90 180 度舵机 ×2（6 元，组成二自由度云台）
  - 电脑自带摄像头（0 元）
  - USB 转 TTL CH340（5 元）
  - 激光头 + 热熔胶（2 元，模拟发射器）
- **系统架构**：上位机（电脑 Python/OpenCV）+ 下位机（STM32）通过串口通讯
  - PC 端：OpenCV 捕捉橙色球 → 计算坐标误差 → PID 计算舵机角度 → 串口发送
  - STM32 端：接收串口数据 → 解析指令 → 输出 PWM 控制舵机
  - 流程：`摄像头 → Python → 串口 → STM32 → 舵机`
- **核心难点**：
  - HSV 颜色空间提取（比 RGB 对光照更鲁棒）
  - 通信协议 `X增量,Y增量\n`，STM32 端用 `sscanf` 解析，检测到 `\n` 才处理（防粘包）
  - PID 控制与消抖：P 项提供响应、D 项提供阻尼防震荡；软件死区（误差 <40px 停止调整）
  - 视差补偿：`OFFSET_X`/`OFFSET_Y`
- **仓库结构**：`Core/`(STM32 HAL 主程序)、`Drivers/`(HAL 驱动)、`ball_track.py`、`color_picker.py`、`pid.py`、`S90_aim_ball.ioc`、CMake 工程
- README 提示：Python 文件在 PyCharm 运行，STM32 在 CLion 运行（配置教程见 B 站 keysking）——**用户决定改用 vscode**

- **第 2 周**：OpenCV 识别橙色球 → `color_picker.py` 调阈值 → PC 串口发 `X增量,Y增量\n` → STM32 解析
