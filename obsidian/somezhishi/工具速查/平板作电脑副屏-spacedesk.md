# 平板作电脑副屏：spacedesk

> 用途：把平板变成电脑的第二块屏幕。本机当前用法——**副屏放 AI 对话，主屏专注代码编辑**，互不遮挡。
> 适合场景：写代码/看网课时不用 Alt+Tab 来回切；平板闲置再利用。

## 是什么

**spacedesk** 是一个把平板（或旧手机、旧电脑）变成 Windows 扩展显示器的免费工具：

- 电脑端装 **Server（服务端）**：负责把桌面画面"切一块"出来编码后发出去
- 平板端装 **Viewer（客户端）**：接收画面并显示，触摸操作会回传给电脑
- 两者通过**同一个局域网（Wi-Fi）**通信

它和 Windows 自带「投影到此电脑」（Miracast）的区别：

| | spacedesk | Miracast（无线显示器） |
|---|---|---|
| 原理 | 局域网 App 传画面 | Wi-Fi Direct 直连 |
| 兼容性 | 平板装 App 就行，安卓/iPad 都可 | 平板需支持 Miracast，兼容性看设备 |
| 延迟 | 一般（可调画质换流畅） | 一般 |
| 网络要求 | 必须在同一局域网 | 不需要路由器 |

## 连接步骤

1. **电脑**：安装 spacedesk Server（Windows 版），装完自动常驻，右下角托盘能看到图标
2. **平板**：应用商店搜 spacedesk，安装 Viewer
3. **同一网络**：电脑和平板连同一个 Wi-Fi（没有 Wi-Fi 时，可用手机热点，或用 USB 网络共享）
4. **平板**：打开 Viewer → 列表里会出现电脑名字 → 点击连接
5. **电脑**：按 `Win + P` → 选「**扩展**」（不要选"复制"，复制只是镜像，扩展才能各用各的）

> [!tip] 扩展 vs 复制
> - **扩展**：两块屏拼成一块大桌面，窗口可以拖到副屏 → 副屏看 AI、主屏写代码就靠它
> - **复制**：两块屏显示完全相同的内容，适合投屏演示，不适合分工

## 双屏分工（本机习惯）

- **主屏**：编辑器 / 终端——专注写代码，不切窗口
- **副屏**：AI 对话、文档、参考资料——需要查的时候扫一眼，不打断主屏
- 窗口拖到副屏：鼠标按住标题栏往屏幕边缘外拖即可

## 踩坑与注意

- **连不上先查网络**：90% 的问题是电脑和平板不在同一网段（比如电脑连网线、平板连 Wi-Fi 而路由器隔离了设备）
- **延迟/画质是跷跷板**：Viewer 里可调分辨率、帧率、画质；写代码看文字优先清晰，卡顿就降帧率
- **平板耗电快**：长时间用建议边充电边用；不然副屏先没电
- **息屏断连**：平板自动息屏会断开，Viewer 设置里把"保持屏幕常亮"打开
- **副屏别放实时性要求高的东西**：视频/游戏会有延迟感，文字类工作完全够用
- **安全提示**：spacedesk 默认在同一局域网内可被发现，公共 Wi-Fi 下用完建议关闭 Server

## 术语小词典

| 术语 | 大白话 |
|---|---|
| Server / Viewer | 服务端（出画面的电脑）/ 客户端（显示画面的平板） |
| 局域网 | 同一个路由器下互相能访问的网络，比如家里同一个 Wi-Fi |
| 扩展模式 | 两块屏拼成一个大桌面，窗口可以拖过来拖过去 |
| 复制模式 | 两块屏显示一样的内容（镜像） |
| Win + P | Windows 快捷呼出"投影"菜单，切换扩展/复制/仅主屏 |
| 延迟 | 平板画面比电脑慢多少，网络差时肉眼可见 |

> [!question]- 自测
> 1. 为什么副屏要用「扩展」而不是「复制」？
> 2. 平板连不上电脑，最先检查什么？
> 3. 平板画面卡顿，可以在哪调设置、优先牺牲什么？
>
> 答案：1. 复制是镜像、两屏内容相同无法分工；扩展才能把 AI 窗口拖到副屏。2. 是否在同一局域网/网段（路由器是否隔离设备）。3. 在 Viewer 的画质设置里调；优先降帧率/画质，保文字清晰。
