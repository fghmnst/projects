# 一生一芯：项目简介与观望记录

> 2026-09-19 调研。结论先说：**本学期不参加、零预算占用；寒假花 2-3 小时低成本试探，W18 期末复盘时定去留**。本卡留档，冬天直接看这份，不用重新调研。

## 它是什么

「一生一芯」（YSYX）是中国科学院大学（国科大）+ 中科院计算所 2019 年发起的**开源处理器芯片教学流片项目**，官网 <https://ysyx.org>。一句话理念：**让一个学生带着自己设计的处理器芯片毕业**。

对零基础读者，先拆几个词：

| 词 | 大白话 |
|---|---|
| 处理器芯片 | 电脑/手机里执行程序的「大脑」（CPU） |
| RISC-V | 一种开放指令集标准，谁都能免费用它设计 CPU（对比 x86/ARM 的授权模式） |
| Verilog / Chisel | 写芯片的「编程语言」——不是让代码一条条执行，而是描述电路长什么样 |
| 流片（tapeout） | 把设计交给工厂真正做成芯片；一次费用极高，所以名额稀缺 |
| 预学习 | 报名后的热身阶段，主要用来想清楚「我是不是真想做」 |

## 培养路线与要求

- **路线**：预学习（Linux / C / 数字电路 / Verilog 基础）→ **B 阶段**（数字设计 + 写一个计算机模拟器 NEMU，打通「程序→指令→信号」）→ **A 阶段**（用 Verilog/Chisel 写 RISC-V 处理器核，含 Cache、SoC 集成）→ **后端流片与回片测试**（线下、受 license 限制，非人人可参与）
- **门槛与费用**：免费、零基础可报、不限年级专业、**全年滚动、随到随学**；免费流片仅限在校生
- **过程要求**：每 1-3 天写学习记录、git log 受检查、每周组会；助教只指方向，不手把手教
- **时间量级**：官方不给统一答案（「因人而异，先试预学习」）；以半年到一年、数百小时计；能否流片取决于是否完成 A 阶段指标，而非耗时
- **激励**：分级认证证书（含助教评语）、入学答辩赠书、积分周边；往届去向含华为海思、北京开源芯片研究院、Synopsys、EPFL/UIUC 等

## 与当前规划的契合度（2026-09 评估）

| 维度 | 判断 |
|---|---|
| 技能树 | 一半 CS（组成原理/体系结构/OS/Linux）+ 一半数字 IC（Verilog/Chisel）；与当前「模拟电路 + 嵌入式应用（STM32/云台）」交集仅 C、Linux、git、调试方法论 |
| 正资产 | C 阶梯（文件 IO/指针/动态内存/Makefile/git）是 B 阶段 NEMU 的硬前置；现有日志/复盘习惯天然匹配它「高频记录 + git log」的节奏 |
| 缺口 | 数字电路、Verilog、体系结构全部为零；本学期课程（模电/复变/概率论/大物）与它几乎不互补 |
| 时间账 | 本学期 22.5h/周 已排满；与 W11-16 云台点火 + CET-6 + 双实验 + 期末正面冲突 |
| 方向叙事 | 锚是港校（机器人/控制/嵌入式）；它是芯片/体系结构方向的强履历，但对当前叙事是分叉，容易变成「第三条战线」 |

## 三个动机的校准（2026-09-19 自述）

- **底层软硬件能力**：C 阶梯 → C++ → STM32 底层已是「浅水版」路线；一生一芯是体系结构/数字 IC 的深水区。试探的目的就是测「想不想游深水」。
- **履历加成**：有分量的是 B/A 阶段甚至流片，**预学习本身不算履历**；承诺前先认清前面是数百小时。
- **人脉**：官方 QQ 群、公开学习记录、SIG 兴趣小组都是真实入口；试探期可先关注官方 B 站号，零承诺。
