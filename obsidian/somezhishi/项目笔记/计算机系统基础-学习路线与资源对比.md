# 计算机系统基础：学习路线与资源对比

> [!note] 结论先行
> 写 [[课程笔记/C语言/命令行参数-argc与argv入门|argc/argv 笔记]] 时对"内核 / ELF / 栈"产生好奇，调研后结论：**本学期不加课**。这块知识叫「计算机系统基础」，讲的是"一行 C 代码怎么变成正在跑的进程"。
> 三档窗口：**现在**（0 预算，工具书按需翻）→ **寒假**（并入一生一芯 2-3h 试探，顺带试听）→ **W18/大二下**（正式选型：CSAPP 稳 / 蒋炎岩 ICS+PA 深）。

## 一、疑问分属哪三块知识

| 疑问 | 知识块 | 经典落点 |
| --- | --- | --- |
| 栈、栈帧、调用约定、寄存器、指令 | 机器级程序（组成原理 / 体系结构） | CSAPP 第 3 章 |
| ELF、`.rodata`、链接、动态链接器 | 链接与装载 | CSAPP 第 7 章；《程序员的自我修养》全书 |
| 内核、`fork`/`execve`、进程、虚拟内存 | 操作系统 | CSAPP 第 8-9 章；OS 专项课 |

## 四、同族概念其实已在露头

这条线的概念在现有工程里一直在出现，不用觉得完全陌生：

- STM32 的链接脚本 `.ld`、启动文件、`crt0`、newlib —— 见 [[somezhishi/项目笔记/STM32工具链-CubeMX与CubeCLT详解|STM32 工具链：CubeMX 与 CubeCLT]]
- gcc / g++ 链接阶段的差异 —— 见 [[somezhishi/环境排障/VSCode-C++插件-IntelliSense配置与gcc-g++区别|VS Code C/C++ 插件]]
- `/proc`、文件描述符、execve —— 见 [[课程笔记/C语言/命令行参数-argc与argv入门|argc/argv 笔记]]

系统课做的事情只是把它们讲透、串成一条线。
