## 二、手动操作事项（换电脑重搭环境必看）

| 序号 | 操作 | 原因/说明 |
|---|---|---|
| 1 | WSL：`sudo apt install -y gcc-arm-none-eabi cmake stlink-tools openocd usbip` | 编译+烧录工具链 |
| 2 | Win 管理员：`winget install --id dorssel.usbipd-win` | USB 直通服务 |
| 3 | Win：`code --install-extension` ×4（cpptools/cmake-tools/cortex-debug/serial-monitor） | vscode 插件 |
| 4 | Win：浏览器装 STM32CubeMX + STM32CubeProgrammer（ST 官网，需注册账号） | GUI 配置 + 烧录/驱动 |
| 5 | Win 管理员：`usbipd list` → `usbipd bind --busid X`（ST-Link 两个 interface 都 bind） | 共享 USB 给 WSL |
| 6 | WSL：`sudo usbip attach -w -b X`（root 权限）→ `lsusb` 验证 0483:3748 | 挂载 ST-Link |
| 7 | CubeMX：新建 F103C8T6 → SYS Serial Wire → HSE 晶振 → 72MHz → PC13 GPIO_Output → CMake 工程 | Lesson 1 动手 2 |
