### Obsidian 启动故障排障（`obsidian-gui` 今天失效）
- **症状**：`obsidian-gui` 后只见 `[WARN:COPY MODE]`，GUI 不弹出
- **根因（两层）**：
  1. `[WARN:COPY MODE]` = AppImage runtime 良性提示（FUSE 不可用 → 解压运行；alias 强制 `APPIMAGE_EXTRACT_AND_RUN=1`），**与故障无关**
  2. 真凶：旧 alias `APPIMAGE_EXTRACT_AND_RUN=1 ~/bin/Obsidian.AppImage &` 后台运行但 **stdout/stderr 仍挂终端**，进程组被作业控制信号挂起（`ps` 见 **T 态**，`wchan=do_signal_stop`），GUI 在初始化前被冻结；且 `~/.config/obsidian/` 残留 **SingletonLock**（指向已无进程的 socket），不清掉会继续挡新实例
- **修复**：`kill` 掉 T 态实例 → 删 `~/.config/obsidian/Singleton{Lock,Cookie,Socket}` + `/tmp/scoped_dirIG0tcx` → **alias 加固**（`~/.bashrc:125`）：
  `nohup env APPIMAGE_EXTRACT_AND_RUN=1 ~/bin/Obsidian.AppImage >/tmp/obsidian.log 2>&1 &`
- **验证通过**：加固后启动进程为 S/Sl 态（正常），GUI 正常弹出

### 晚上：STM32Cube 扩展 v3.10 `.settings` 排障（22:44-23:41，跨日）
- **症状链**：① CMake Tools 报 `Cannot configure: No configure preset is active`（build failed code -1）→ 原因：新工程首次打开未选 configure preset + **ninja 未安装**（preset generator=Ninja）→ 修：装 `ninja-build` + 选 preset → 22:55 编译成功（RAM 1584B / FLASH 4852B，DDM_test.elf 生成）→ ② 编译成功后扩展持续报 `ENOENT: no such file or directory, open 'DDM_test/.settings/ide.store.json'`
- **根因**：STM32Cube 扩展 v3.10 是 STM32CubeIDE 新架构（stm32cube-ide-* 共 13 个扩展），bundles-manager 激活即调 cube CLI 读工程上下文（`.settings/bundles.store.json`）；工程从未被「设置 STM32Cube 项目」流程初始化过 → 全家报错
- **关键坑**：命令面板「设置 STM32Cube 项目」**灰色不可点**（enablement `isCubeCMakeProject`，仅在项目发现 discovery 找到 ≥1 工程时置 true）→ 点击无任何反应（用户现象：「什么都没发生」）；discovery 失败静默（`Cube project setup failed` 只进扩展宿主 console）
- **源码逆向结论**：discovery 流程 = `getSiblingProjects` → `ProjectAPI.findProjects(工作区根)`（识别 CMakeLists.txt 等标记）→ `checkWorkspaceFolderConsistency`（**要求工程位于工作区文件夹根**，projects/ 根窗口必然失败）→ 分类（isCubeProject / isUncubifiedCubeProject）
- **修复路径**：`cube bundle init --project`（手动创建 `.settings/bundles.store.json`，绕过扩展 UI）→ `cube bundle list --project` 验证通过 → 手补 `ide.store.json`（内容 `{}`）→ 远程用户设置关闭 webview 向导 `stm32cube-ide-build-cmake.project-setup.incubationWebview: false`（写 `~/.vscode-server/data/User/settings.json`）
- **结局**：8-12 重启电脑后 `.settings/` 由扩展自动下载配置成功（bundles.store.json / bundles-lock.store.json / ide.store.json 全部就位）——重启让扩展重新初始化 + init 生效；**精确根因未完全定位**
