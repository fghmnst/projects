### 晚上 session（20:57-23:58 · plan → build）

- **发送键改回 Enter**：`~/.config/opencode/tui.json` 的 `input_submit` 由 `ctrl+return` 改回 `return`（`input_newline` 同步移除 `enter` 避免冲突），`alt+p`/`alt+f` 不动。原因：Windows 自带 bash 终端不支持 ctrl+enter 发送。TUI 速查表笔记同步更新（commit `943d617`）
- **AGENTS.md 约定放宽**：Obsidian 操作从「一律走 CLI、禁改源文件」改为「优先 CLI；纯 markdown 可直接改源文件；涉及 wikilinks 等特色功能必须用 CLI」
- **共享交互终端可行性调研**：opencode 无内置共用终端；结论用 tmux 共享会话方案（本机已装 tmux 3.4），待云服务器场景落地
- **Hermes 云端部署（本日重头戏）**：
  - ssh 配置迁移：Windows `~/.ssh/config` → WSL（server1/server2 别名），两平台共用同一把 ed25519 密钥
  - 服务器准备：时区改 Asia/Shanghai；生成 GitHub 专用密钥 + 公钥加入账号；clone 私有仓库 `fghmnst/projects` 到 `~/projects`
  - QQ Bot 接入：`QQ_APP_ID`/`QQ_CLIENT_SECRET` 写入 `~/.hermes/.env`；`config.yaml` 启用 `platforms.qqbot`
  - Gateway 持久化：`sudo hermes gateway install --system`（开机自启），解决 nohup 被 ssh 断开杀掉的崩溃问题
  - 排障实录：`dm_policy: open` 未配 opt-in 导致 gateway 崩溃循环（`Refusing to start`）→ 加 `QQ_ALLOW_ALL_USERS=true` 解锁 → 抓 OpenID（`[QQ_OPENID_REDACTED]`）→ 收紧为 `allowlist + allow_from`
  - **cron 任务 daily-digest 上线**：`0 7 * * *`，`--deliver qqbot --workdir ~/projects`，下次运行 2026-08-07 07:00 (+08:00)
  - **端到端测试成功**：手动触发后报告生成并 `delivered to qqbot:08942AFB...612`，QQ 收到推送
