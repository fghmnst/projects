# Lesson 0001 · 工具链与第一个 C++ 程序

> 本课里程碑：**在终端编译并运行你的第一个 C++ 程序**
> 预计用时：30-45 分钟 · 绑定 [[../MISSION.md|Mission]]

## 本课你会得到什么

一个能跑的程序（"Hello Snake!"），以及一条后续所有课程都用的编译命令。之后每课都建立在"我会编译运行"之上——这是最小可行起点。

## 一、知识：源代码是怎么变成程序的

你已经知道 C 的流程，C++ 完全一样：

```
hello.cpp（源代码，人能读）──g++──▶ hello（可执行文件，机器能跑）
```

**编译（compile）**：把 `.cpp` 源代码翻译成机器指令的程序，叫**编译器（compiler）**。我们用的是 g++（GCC 的 C++ 编译器）。

> [!note] 术语
> **g++**：C++ 编译器，Linux 自带。你机器上是 13.3 版。
> **可执行文件（executable）**：编译产物，直接在终端运行。

## 二、第一个程序：对比 C

> [!info] 你会一点 C，所以我直接给你对照，不重复讲语法基础。

```c
// hello.c —— 你会写的 C 写法
#include <stdio.h>
int main() {
    printf("Hello Snake!\n");
    return 0;
}
```

```cpp
// hello.cpp —— 今天的 C++ 写法
#include <iostream>
int main() {
    std::cout << "Hello Snake!\n";
    return 0;
}
```

逐行对比，C++ 多了三样新东西：

| | C | C++ | 区别是什么 |
|---|---|---|---|
| 头文件 | `#include <stdio.h>` | `#include <iostream>` | iostream = 输入输出流（in-out stream） |
| 输出 | `printf("...")` | `std::cout << "..."` | **流（stream）**：把数据"流向"终端。`<<` 是流向操作符 |
| 前缀 | 无 | `std::` | **命名空间（namespace）**：`std` 是 C++ 标准库的家 |

### 1. `std::cout` 为什么比 `printf` 好

- `printf` 靠格式串 `%d %f %s` 匹配参数类型——写错类型，编译期不报错，运行期打印垃圾。
- `cout` 不用格式串，类型自动匹配：`std::cout << 42 << " 和 " << 3.14 << '\n';` 各写各的，类型错了编译期就报错。
- 这就是 C++ 的哲学之一：**把错误尽早暴露在编译期**。

### 2. `std::` 前缀与 `using`

`std::cout` 全名是"命名空间 std 里的 cout"。每次都写 `std::` 啰嗦但明确，养成习惯（大项目必须如此）。偷懒写法是 `using namespace std;`，**本课程一律不用**——你会先遇到足够多冲突场景再决定要不要用。

> [!question] 小思考
> `std::endl` 和 `'\n'` 效果上都是换行，但 endl 还会"冲洗缓冲区"。这里先记住：贪吃蛇后续每次打印用 `'\n'` 就够了，endl 我们到课程后面再说细节。

## 三、动手：写它，编译它，运行它

1. 建目录：`mkdir -p ~/projects/CppSnake && cd ~/projects/CppSnake`
2. 创建 `hello.cpp`（用 vscode，内容就是上面 C++ 那段）
3. 编译：

```bash
g++ -Wall hello.cpp -o hello
```

> [!tip] `-Wall` 是「打开全部警告（warnings）」——C++ 里警告几乎都是你写错的线索，永远开着。
> `-o hello` 指定输出文件名叫 `hello`（不写默认叫 `a.out`）。

4. 运行：`./hello`

看到 `Hello Snake!` 即成功。试试把 `'\n'` 删掉重编译——观察输出差异，再改回来。

## 四、练习（动手才能记住）

> [!example] 练习 1（5 分钟）
> 把 `"Hello Snake!"` 改成两行：`std::cout << "Snake 1\nSnake 2\n";`——注意 `\n` 在字符串**里面**也有效。编译运行。

> [!example] 练习 2（10 分钟，稍烧脑）
> 用一条 `std::cout << ...` 语句打印三个值：你的名字、当前年份、一个数字，各占一行。提示：`<<` 可以连续接多个值和字符串。

> [!example] 练习 3（5 分钟，故意踩坑）
> 把第 3 行 `std::cout` 的 `std::` 删掉，只留 `cout`，编译。**记录报错信息**——这是你第一次见到 C++ 编译错误，以后每天都会见它。报错后改回来。

> [!note] 编译报错了怎么办
> 报错信息读法：`文件名:行号:错误内容`。先看**第一个**错误（后面的经常是连锁反应）。看不懂就把它复制发给 agent 老师（就是我）——**这是本课程最重要的一条提醒：任何一步卡住，随时问我**，我的回复和你的记录都会变成你的学习资料。
