# C++ 贪吃蛇课程术语表

本术语表记录用户在课程中**已经理解**的术语（规则：用户理解后才收录，见 [[../NOTES.md]]）。定义遵循本课程用法。

## 工具链

**编译（compile）**:
把源代码翻译成机器可执行程序的过程，由编译器完成。
_Avoid_: 打包、生成

**编译器（compiler）**:
执行编译的程序。本课程用 g++（GCC 的 C++ 编译器）。
_Avoid_: 翻译器

**可执行文件（executable）**:
编译的产物，可在终端直接运行的程序文件。
_Avoid_: 安装包

**g++**:
GNU C++ 编译器，命令行工具。`g++ -Wall 源文件.cpp -o 输出名` 是编译命令。
_Avoid_: 编译器（当需要指名时）

## 输入输出

**流（stream）**:
数据按顺序"流动"的通道。`std::cout`（标准输出流）把数据流向终端。
_Avoid_: 打印函数

**命名空间（namespace）**:
名字的集合容器，避免重名冲突。`std` 是 C++ 标准库的命名空间，所以写 `std::cout`。
_Avoid_: 包、库
