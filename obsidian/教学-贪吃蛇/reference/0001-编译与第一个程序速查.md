# 速查表 0001 · 编译命令与 cout

> 课程：[[../lessons/0001-工具链与第一个程序|0001 工具链与第一个程序]] · 反复查阅用，不必记住

## 编译与运行

```bash
g++ -Wall hello.cpp -o hello   # 编译：-Wall 开警告，-o 定输出名
./hello                        # 运行
```

- 忘了 `-o` → 产物叫 `a.out`
- 改完代码必须**重新编译**再运行（运行的是编译产物，不是源码）
- 报错格式：`文件:行号:错误`；先修第一个错误

## 输出 cout

```cpp
#include <iostream>          // 头文件：输入输出流

int main() {
    std::cout << "Hello\n";  // 字符串 + 换行
    std::cout << 42 << '\n'; // 数字，无需格式串，类型自动匹配
    std::cout << "a" << "b" << 3;  // << 可连续拼接
    return 0;                // main 返回 0 = 正常结束
}
```

- `'\n'`（字符）与 `"\n"`（字符串里的换行）都行；`std::endl` 也可换行但会冲洗缓冲，贪吃蛇里用 `'\n'` 足够
- 删掉 `std::` 前缀会编译报错：`'cout' was not declared in this scope` —— 这是日常最常见的错误

## 常见坑

| 现象 | 原因 |
|---|---|
| 改了代码没变化 | 没重新编译 |
| `cout` 未定义 | 忘了 `std::` 或忘了 `#include <iostream>` |
| `main` 没写 `return 0` | 不报错（C++ 默认返回 0），但养成写它的习惯 |
