# 0001 · 先验知识：会一点 C 语言

用户披露具备基础 C 能力：变量、循环、函数、数组、指针（`printf` 时代的写法）都懂；未接触过 C++ 的类、STL、命名空间。教学方向已在 [[../MISSION.md|MISSION]] 定型：跳过 C 已有内容，直击 C++ 独有部分（引用、类、STL 容器、iostream）。

## Implications

- 0001 课用「C 对照 C++」的方式引入（printf → cout、stdio.h → iostream），不重讲语法基础。
- 指针已知 → 0004 课讲引用时可与指针对照，作为桥梁而非从零教。
- 数组已知 → 0002/0003 讲 vector/queue 时用「C 数组的痛」做动机引入。
- 术语表只收录用户已理解的术语；C 已知术语（如"变量"）不重复收录。
