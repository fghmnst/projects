# 面包板接线：最小系统板横跨与电源轨

> 2026-08-19 记录。解答：为什么江科大教程把最小系统板横跨面包板，并把 3.3V / GND 接到两侧电源轨。

## 面包板结构

```
┌─────────────────────────────────────┐
│  + 电源轨 │  区 A  │ 区 B  │ 电源轨  + │  ← 两侧长条是电源轨
│  - 地轨   │        │       │ 地轨    - │     (power rail)
│  + 电源轨 │  区 A  │ 区 B  │ 电源轨  + │
└─────────────────────────────────────┘
        ▲    ▲    凹槽   ▲
   左排针落这里      右排针落这里
```

关键事实：中间凹槽**左右两侧区域互不连通**；两侧的电源轨（红 `+` / 蓝 `-` 长条）也**各自独立、不连通**。

## 为什么横跨 + 为什么接 3.3V/GND

1. **横跨 = 把核心板左右两排排针分别送到区 A 和区 B**，外设可放在板子两侧就近接线，不挤在一边。
2. **3.3V/GND 跳线的目的 = 给面包板铺「电源总线」**：
   - 3.3V 引脚 → 一侧电源轨，GND 引脚 → 另一侧电源轨
   - 之后所有外设（LED、按键、OLED、传感器）**直接从电源轨取电**，不用每次从核心板引脚飞长线
3. **共地是必须的**：外设要与核心板共享地电位，信号才正确。电源轨把 GND 铺开 = 给所有外设统一「地」。

## 与 ST-Link 供电的关系（易混点）

- **ST-Link 供核心板**（SWD 口给 3.3V，点亮 LED 只需这一步）
- **电源轨供外设**（核心板 3.3V/GND 引脚引出到面包板两侧长条）
- 两者是两回事：单点灯不需要电源轨，后续多外设实验必须靠电源轨取电 + 共地

一句话：**横跨是为了左右都能用，接 3.3V/GND 是为了把电源「引」到整个面包板两侧。**

## 延伸

- 左右电源轨在凹槽处不连通，若两侧都要 3.3V，需用跳线桥接左右电源轨
- 面包板轨只适合小电流器件（LED、传感器等），大电流（舵机 5V/2A）必须独立供电，见 [[术语表/术语表|术语表]] 相关约定与主项目「已知坑」
