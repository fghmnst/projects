# 舵机接线：双 SG90 供电与共地全解

> 2026-08-19 创建。火控云台双舵机的接线方案、供电架构、共地原理与正极注意事项。配套：[[模块笔记/面包板接线|面包板接线]]、测试程序 `fire_control/servo_test.py`。

## 引脚分配（STM32F103C8T6, LQFP48）

| 引脚 | 复用功能 | 用途 |
|---|---|---|
| PA0 | TIM2_CH1 PWM | X 舵机信号（水平） |
| PA1 | TIM2_CH2 PWM | Y 舵机信号（垂直） |
| PA9 | USART1_TX | → CH340 RX |
| PA10 | USART1_RX | ← CH340 TX |
| PA13/PA14 | SWD | ST-Link 烧录（不动） |

TIM2 配置：Prescaler 71 / Period 19999（72MHz → 1MHz 计数 → 50Hz），Pulse 500–2500 = 0.5–2.5ms = 0–180°，中心 1500 = 90°。SG90 三线：**棕=GND、红=VCC、橙=信号**（杂牌线序可能不同，接前看标签）。

## 供电架构（双电源）

```
ST-Link ──SWD──► 核心板 3.3V       ← ST-Link 只喂核心板
18650 3.7-4.2V ──► 舵机1红 + 舵机2红  ← 电池只喂舵机
18650 GND ──► 舵机1棕 + 舵机2棕 ──► 面包板 GND 轨
GND 轨 ──跳线──► STM32 GND 排针      ← 共地动作（必须做！）
信号：PA0/PA1 ──► 舵机橙线
```

**铁律**：
1. 舵机红/棕线**绝不接** STM32 的 3.3V/5V/GND 引脚（SG90 堵转电流 700mA+，ST-Link/USB 供不起）
2. 两个电源的**正极绝不交叉**（18650 正极只碰舵机红线；碰 3.3V 引脚会反向灌电烧板，碰 5V 引脚会与 LDO 环流）
3. **地是唯一允许共用的点**（下面详解）

## 共地详解

**为什么必须共地**：信号是电位差。STM32 输出 3.3V = 相对自己 GND 有 3.3V。舵机判断 PWM 高/低电平 = 相对**自己的 GND**。两个电源不共地时 A/B 两个参考点电位不一致 → 高电平判定漂移 → 舵机乱转/不动/信号线成为唯一回流路径。

**怎么做**：把 18650 负极、舵机棕线、STM32 GND 排针都汇聚到**面包板 GND 轨**（一条长铜条，天然共地总线）。

**验证**：万用表蜂鸣档量 STM32 GND 排针 ↔ 18650 负极 → 应导通（<1Ω）；电压档 → 0V（几 mV 正常）。

**不共地的症状**：舵机抖动/乱转/时动时不动；GPIO 量着有 3.3V 但舵机不动；插信号线后核心板复位。

## 接线合法性总表

| 连接 | 允许 | 原因 |
|---|---|---|
| 18650+ → 舵机红 | ✓ | 舵机唯一电源 |
| 18650− → 舵机棕 + GND 轨 | ✓ | 供电回路 + 共地 |
| GND 轨 → STM32 GND 排针 | ✓ | 共地动作，必须做 |
| 18650+ → STM32 3.3V/5V | ✗ | 反向灌电、环流、烧板 |
| ST-Link → 舵机红 | ✗ | 电流不够，触发过流复位 |
| 两电源正极并联 | ✗ | 电压高者灌低者，电流失控 |

## 现状与升级路径

- **当前（临时）**：单节 18650 直连双舵机。3.7–4.2V < SG90 下限 4.8V → **Y 舵机力矩不足、动作不灵活**（实测现象），测试可用但不适合真实追踪。
- **升级方案（零件到货后）**：5V/2A 独立电源（手机充电器 + 面包板供电模块，或 2×18650 串 7.4V + 降压模块调 5V）。接线只动红/棕线，信号线不变。注意 18650 过放 <3.0V 会永久损伤（带保护板电池自动断电）。

## 测试程序

`fire_control/servo_test.py`（WASD 双舵机测试）：termios 单键读取，a/d → X 舵机左右、w/s → Y 舵机上下，`FLIP_X`/`FLIP_Y` 方向翻转，`STEP` 步长。协议 `X增量,Y增量\n` @115200（与主项目 `ball_track.py` 同一协议——键盘测试=模拟视觉，顺便验证通信链路）。运行：`python3 fire_control/servo_test.py`。

## 已知坑

- SG90 虚位大、有死区：需 PD 控制 + 软件死区（误差 <40px 停止调整）
- 2×SG90 需 5V/2A 独立供电，不要全从板子 USB 口取电
