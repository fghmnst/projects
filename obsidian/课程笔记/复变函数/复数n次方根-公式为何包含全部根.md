# 复数 n 次方根：公式为何包含全部根（新手版）

> [!note] 一句话先行
> 求 $w^n = z$ 的根时，推出的其实是**转角同余式** $n\varphi \equiv \theta \pmod{2\pi}$，而不是普通等式 $\varphi = \theta/n$。"同余"的意思是"表盘上相差整圈就算同一格"——这个条件在表盘上恰好有 $n$ 个不同落点，所以公式一写出来就自动把全部根都列齐了，并不是"先算一个、再另外补几个"。
> 下面先用表盘画面建立直觉，所有术语当场解释；文末有术语小词典与自测。

## 一、先建画面：复数像表盘上的指针

**复数** $z = x + yi$ 是平面上的一个点。换个方式看它：把点看成一支从原点出发的**箭头**。

- 箭头有多长？这叫**模**（记 $|z|$ 或 $r$）：$|z| = \sqrt{x^2+y^2}$，就是它到原点的距离。
- 箭头指向哪个方向？这叫**辐角**（argument），是从正实轴（指向右边的方向）逆时针量起的转角。

> [!tip] 记号约定：大写 $\operatorname{Arg} z$ 与小写 $\arg z$
> - **大写 $\operatorname{Arg} z$** = 该点的**全部**辐角，多值：$\operatorname{Arg} z = \arg z + 2k\pi$（$k\in\mathbb{Z}$）；
> - **小写 $\arg z$** = **主辐角**（主值）：从全部辐角中挑出一个当代表，本课约定取 $-\pi < \arg z \le \pi$；
> - 本文正文里的 $\theta$ 泛指"某个辐角代表"（是 $\operatorname{Arg} z$ 中的一个值）；做题书写时按上面的大小写约定；
> - ⚠️ 英文教材（Ahlfors、Churchill 等）大小写含义常与此**相反**，翻书前先看它的记号说明。

用"长度 + 方向"写出来的式子叫**三角式**（也叫极式）：

$$z = r(\cos\theta + i\sin\theta)$$

**关键画面**：角度不止 $0$ 到 $2\pi$ 这一圈。像时钟指针"再转一圈"会回到原处一样，同一个方向的辐角可以写成 $\theta$、$\theta+2\pi$、$\theta-2\pi$、$\theta+4\pi$……无限多个，彼此相差 $2\pi$ 的整数倍。这叫辐角的**多值性**——记住它，后面出现 $2k\pi$ 全靠它。

## 二、复数乘法：长度相乘，方向转圈

要把 $w$ 开 $n$ 次方，先看 $w$ 自己乘自己会发生什么。设 $w = \rho(\cos\varphi + i\sin\varphi)$，用三角恒等式展开可得

$$w^n = \rho^n\bigl(\cos(n\varphi) + i\sin(n\varphi)\bigr)$$

画面读法：**每乘一次 $w$，箭头长度就乘以 $\rho$，方向就转过 $\varphi$ 角**。乘 $n$ 次，长度变成 $\rho^n$，方向一共转过 $n\varphi$。

于是"求 $w^n = z$ 的根"就是反着问：**哪支箭头，长度自乘 $n$ 次后等于 $r$、方向转 $n$ 次后回到 $\theta$（允许途中多转整圈）？**

## 三、关键一步：$2k\pi$ 是怎么出现的

设 $z = r(\cos\theta + i\sin\theta)$，$w = \rho(\cos\varphi + i\sin\varphi)$。要求 $w^n = z$：

$$\rho^n\bigl(\cos(n\varphi) + i\sin(n\varphi)\bigr) = r(\cos\theta + i\sin\theta)$$

两边是两个复数，"相等"意味着长度一样、方向一样（允许差整圈），于是拆成两个条件：

$$
\begin{cases}
\rho^n = r \\[2pt]
n\varphi = \theta + 2k\pi, \quad k \in \mathbb{Z}
\end{cases}
$$

- **长度**：$\rho = r^{1/n}$，**唯一**。理由：正实数开 $n$ 次方只有一个答案（比如 $2$ 的平方根只取非负的 $2^{1/2}$，没有第二个正数）。
- **方向**：右边为什么必须带 $2k\pi$？因为"$\theta$ 方向"和"$\theta$ 再转 $k$ 整圈"是同一个方向（表盘画面）。漏掉 $2k\pi$，等于硬性假设转的圈数正好是 0，自然就会漏根。

把 $2k\pi$ 除过去，得到

$$\varphi_k = \frac{\theta + 2k\pi}{n}, \qquad k = 0, 1, \dots, n-1$$

**为什么 $k$ 取到 $n-1$ 就停？** 因为 $\cos$、$\sin$ 以 $2\pi$ 为周期：$k$ 与 $k+n$ 算出的转角相差 $2\pi$，表示同一个点；$k=-1$ 也等于 $k=n-1$。表盘上互不重复的落点恰好 $n$ 个。

于是全部根是

$$w_k = r^{1/n}\left(\cos\frac{\theta+2k\pi}{n} + i\sin\frac{\theta+2k\pi}{n}\right), \quad k = 0, \dots, n-1$$

相邻两个根的方向相差 $2\pi/n$——**$n$ 个根恰好是正 $n$ 边形的顶点**。

## 四、为什么"全部"都在里面（完备性）

随便拿一个根 $w$，它必须同时满足两件事：

1. 长度 $|w| = r^{1/n}$——被方程死死钉住，没有别的选择；
2. 方向满足 $n\varphi \equiv \theta \pmod{2\pi}$——只能落在表盘等分出来的 $n$ 个方向之一。

两个条件都是被迫的，所以任何根都逃不出列表；反过来，列表里每个根代进去都成立。一个不多、一个不少。

两个互相印证的视角：

- **单位根**：如果已经找到一根 $w_0$，那么其余根 = $w_0$ 乘上"转 $k$ 格"的因子 $\zeta_k = e^{2\pi ik/n}$。这些 $\zeta_k$ 满足 $\zeta^n = 1$，叫 **$n$ 次单位根**——就是把 $1$ 开 $n$ 次方得到的 $n$ 个点，均匀分布在单位圆上；
- **代数基本定理**：$w^n - z = 0$ 是 $n$ 次多项式方程，恰好有 $n$ 个根（计重数）。我们已找到 $n$ 个互异的根，已经找全。

## 五、换一个代表元不丢根

$z$ 的辐角本来就有无穷多种写法：$\theta + 2m\pi$（$m$ 为任意整数）。用 $\theta + 2m\pi$ 代替 $\theta$ 重新算一遍：

$$\varphi'_k = \frac{\theta + 2m\pi + 2k\pi}{n} = \varphi_{k+m}$$

只是把编号整体挪了 $m$ 格，根的**集合**完全不变。所以"取主辐角 $\arg z$"（从全部辐角 $\operatorname{Arg} z$ 中挑一个代表）只是一种"选个起跑线"的约定，不影响结果。

## 六、例子：$-8$ 的立方根

$-8$ 的模 $r = 8$，辐角 $\theta = \pi$（箭头指向左边）。取 $n = 3$：

$$\varphi_k = \frac{\pi + 2k\pi}{3}$$

| $k$ | 转角 | 根 | 备注 |
| --- | --- | --- | --- |
| 0 | $\pi/3$（60°） | $1 + \sqrt{3}\,i$ | 主值 |
| 1 | $\pi$（180°） | $-2$ | **实数立方根在这里**，不在 $k=0$ |
| 2 | $5\pi/3$（300°） | $1 - \sqrt{3}\,i$ | |

三个根连起来是正三角形。值得多想一步：实数范围里 $-8$ 的立方根只有一个（$-2$），复数范围里却有三个——多出来的两个是"转到别处"的解，在实数轴上"看不见"，但真实存在。

## 七、常见疑问

- **"只算出一个根"是怎么回事？** 那是设了 $k=0$（取主值 $\arg z$）。正确读法不是"再补 $n-1$ 个根"，而是"同余式本来就列出 $n$ 个"——写成 $2k\pi$ 的那一刻，全部根已经同时在公式里了。
- **为什么说 $z^{1/n}$ 是多值的？** 同一个 $z$ 对应 $n$ 个不同的值，是一次输入多个输出。中学的根号 $\sqrt{\ }$ 是人为规定"只取非负的那个"（叫**算术根**）；复数里没有这种自然规定，只能自己约定一个（如主值），其余的就是别的"支"。
- **多值还叫函数吗？** 多值函数可以想象成"一个把戏分成 $n$ 层"，每一层（术语叫**单值分支**）单独看都是正常函数；在层与层之间来回切换会突然跳变。这是后面"黎曼面"要处理的问题，现在只需记住：多值性是复数开方的固有属性。
- **$0$ 开 $n$ 次方呢？** 模长为 $0$ 时方向失去意义，$n$ 个候选点坍缩成同一个 $0$：$0$ 只有一个 $n$ 次方根。公式取 $r=0$ 会自动反映这一点（所有 $k$ 给出同一个点）。
- **为什么恰好 $n$ 个，而不是无穷多个？** 辐角确实有无穷多种写法，但"相差整圈"的写法在表盘上是同一个方向；按方向去重之后只剩 $n$ 类。无穷多被"圈数不作数"压缩成了有限。

## 八、自测（想不起来就翻上文）

> [!question]- 不用公式，直接说出 $z = 1$ 的 4 次方根。
> 就是问"哪支箭头转 4 次后回到方向 $0$、长度还是 $1$"。把表盘四等分：$1,\ i,\ -1,\ -i$（转角 $0,\ \pi/2,\ \pi,\ 3\pi/2$），正是 4 次单位根。

> [!question]- $k = 0$ 与 $k = n$ 给出的根一样吗？为什么？
> 一样。$\varphi_n = \frac{\theta + 2n\pi}{n} = \varphi_0 + 2\pi$，两者方向差一整圈，表示同一个复数。所以编号只需取 $0,\dots,n-1$。

> [!question]- 已知 $w_0$ 是 $w^3 = z$ 的一个根，怎样立刻写出另外两个？
> 乘 3 次单位根：$w_0\omega$ 与 $w_0\omega^2$，其中 $\omega = e^{2\pi i/3} = -\frac12 + \frac{\sqrt3}{2}i$。相当于把 $w_0$ 绕原点转 $120°$ 和 $240°$。

## 九、术语小词典（复习用）

| 术语 | 通俗解释 | 正式一点的说法 |
| --- | --- | --- |
| 复数 / 实部 / 虚部 | 平面上的点，也就是一支箭头 | $z = x + yi$ |
| 模 | 箭头长度、到原点的距离 | $\lvert z\rvert = \sqrt{x^2+y^2}$ |
| 辐角 $\operatorname{Arg} z$ | 箭头方向的转角，可差整数圈（大写 = 全部、多值） | $\operatorname{Arg} z = \arg z + 2k\pi$，$k\in\mathbb{Z}$ |
| 主辐角 $\arg z$ | 从约定区间里挑一个转角当代表（小写 = 主值） | $-\pi < \arg z \le \pi$（本课约定） |
| 三角式（极式） | "长度 + 方向"的写法 | $z = r(\cos\theta + i\sin\theta)$ |
| 同余式 | "表盘上相差整圈算同一格"的等式 | $a \equiv b \pmod{2\pi}$ |
| $n$ 次单位根 | 把 $1$ 开 $n$ 次方得到的 $n$ 个点 | $\zeta_k = e^{2\pi ik/n}$，$\zeta_k^n = 1$ |
| 代数基本定理 | $n$ 次多项式方程恰有 $n$ 个根 | 复数域上 $n$ 次方程恰 $n$ 根（计重数） |
| 多值函数 / 单值分支 | 一个输入对多个输出；把多值拆成一层层正常函数 | 分支理论（后续黎曼面） |
| 算术根 | 中学的 $\sqrt{\ }$：规定只取非负值 | 非负实数的非负平方根 |
| 重数 | 同一个根被重复计算几次 | 例：$(w-1)^2$ 在 $w=1$ 有 2 重根 |
