# 单值函数、多值函数、单叶函数：为何只有单叶可求反函数（新手版）

> [!note] 一句话先行
> 把函数想成一台"箭头机"：每个输入点射出一支箭到输出点。
>
> - **单值函数**：每个输入**只发一支箭**（前向不劈叉）——这是"函数"一词的默认含义；
> - **多值函数**：每个输入**可能发多支箭**（一个输入对多个输出），严格说它不是函数；选出一条"分支"后才变回函数；
> - **单叶函数**：先单值，再要求**没有两支不同的箭落在同一点**（后向不合并，即"单射"）。
>
> 反函数就是把所有箭头**掉头**：只要有一对箭合并过，掉头后就会"一进两出"，违反单值性——所以**只有单叶（不合并）的函数才能掉头**，得到单值的反函数。
> 术语都在当场用大白话解释；文末有术语小词典和自测。

## 一、先建画面：函数是一台"箭头机"

**函数** $f$ 是一条对应规则：给每个输入 $z$（复平面上的点），按规定送出输出 $w=f(z)$。

画成图：从每个 $z$ 点射出一支箭，落到 $w$ 点。围绕这台机器只需要问两个问题：

1. **每个输入发出几支箭？** —— 决定它是单值还是多值；
2. **有没有两支箭落在同一个落点？** —— 决定它是不是单叶。

两个问题互相独立，所以"单值"和"单叶"是两回事（例子见第三节）。

## 二、三个定义（人话版）

**单值函数**：对定义域中每个 $z$，有**唯一确定**的 $w$ 与之对应。"一个输入、恰好一个输出"——中学的函数都是单值函数。

**多值函数**：对每个 $z$，对应的 $w$ **不止一个**。例如 $\arg z$：同一个点的方向可以写成 $\theta$、$\theta\pm2\pi$、$\theta\pm4\pi$……无穷多个。严格说多值函数不是函数，而是一种**对应关系**（一入多出）；按某种规则从多个输出中"挑出一条"（在每一点都一致地挑），挑出来的东西才是一个真正的函数，叫做它的**单值分支**。

**单叶函数**：设 $f$ 在区域 $D$ 上先是个单值函数。若对 $D$ 内**任意两个不同点** $z_1\neq z_2$，都有

$$f(z_1)\neq f(z_2)$$

则称 $f$ 在 $D$ 上**单叶**（univalent，德语 schlicht）。通俗说：**不同的输入绝不给出相同的输出**——也就是"单射""一一对应"。
"**叶**"的画面：单叶函数的像不叠自己，只铺一层纸；非单叶函数的像会叠起来（有的角落铺两层、三层）。

> [!warning] 关键辨析：单值 ≠ 单叶
> - $f(z)=z^2$：每个输入只有一个输出（**单值**），但 $1$ 与 $-1$ 都给出 $1$（**不单叶**）；
> - 单叶要求更强：先单值，再加"不粘点"。
> - 两个词一字之差，考试最爱在这里挖坑。

## 三、例子大全

| 类型 | 例子 | 为什么 |
| --- | --- | --- |
| 单值但**非**单叶 | $f(z)=z^2$ | $1$ 与 $-1$ 都被"粘"到 $1$ |
| | $f(z)=e^z$ | $z$ 与 $z+2\pi i$ 落在同一点 |
| | $f(z)=\lvert z\rvert$（实值） | 整个圆周上的点都压成同一个值 |
| | 常数函数 | 极端情形：所有输入粘成一团 |
| 单值**且单叶** | $f(z)=z$、$f(z)=2z+1$ | 平移、旋转、放缩，不劈叉也不合并 |
| | $z^2$ 限制在右半平面 $\operatorname{Re}z>0$ | 两个"孪生点" $z$ 与 $-z$ 只剩一个 |
| | $e^z$ 限制在水平条 $-\pi<\operatorname{Im}z<\pi$ | $z$ 与 $z+2\pi ik$ 只剩一个 |
| | $f(z)=\dfrac{1}{z}$ 在 $\mathbb{C}\setminus\{0\}$ 上 | 不同的点倒数必不同 |
| 多值 | $\arg z$ | 每点无穷多个辐角 |
| | $z^{1/n}$ | 每点 $n$ 个值（正 $n$ 边形顶点） |
| | $\log z$ | 每点无穷多个值（相差 $2k\pi i$） |
| | $\arcsin z$ 等反三角 | 每点无穷多个值 |

**中学类比**：$y=x^2$ 在实数轴上不单叶（$1$ 与 $-1$ 都到 $1$），所以不能直接求反函数；把定义域限成 $x\ge0$ 后就单叶了，反函数 $\sqrt{x}$ 才存在。复数只是把"两个方向"换成了"绕圈"（$z$ 与 $z+2\pi ik$ 的关系），道理一模一样。

## 四、为什么只有单叶函数能求反函数

**反函数的本质：把箭头全部掉头。** 掉头后的对应关系是

$$f^{-1}(w)=\{\,z\in D: f(z)=w\,\}$$

（"所有落到 $w$ 的输入"）。它是**函数**的条件是：每个 $w$ 恰好有一个原像。

- 若 $f$ 单叶：每个落点只有一支箭来，掉头后每个 $w$ 恰好回到一个 $z$ —— 得到单值反函数；
- 若 $f$ **不**单叶：存在 $z_1\neq z_2$ 但 $f(z_1)=f(z_2)=w$，掉头后 $w$ 要同时回到 $z_1$ 和 $z_2$，"一进两出"，违反单值性。此时 $f^{-1}(w)$ 含两个元素，是一个**多值**的对应关系。

精确说法：**$f:D\to f(D)$ 有单值反函数 $\iff$ $f$ 在 $D$ 上单叶。** 反函数只要求定义在**值域** $f(D)$ 上（函数"能到达的地方"），所以"满射"是自动的；唯一要卡的条件就是"单射"，即单叶。这就是"只有单叶可定义反函数"的全部含义。

把 $z^2$ 当例子走一遍：$z$ 与 $-z$ 被粘到同一个 $w$。掉头看，$w$ 必须分叉回两个地方，所以"$\sqrt{w}$"天生两值。想让它变成正常函数，就得**先把 $z^2$ 限制到一块单叶的区域**（比如右半平面），再掉头——这就是"选单值分支"，得到主支 $\sqrt{w}$（取值为右半平面）。$\log w$、$\sqrt[n]{w}$ 全是同一套路。

两个补充（以后会用到）：

- **局部版**：若 $f$ 在 $z_0$ 解析且 $f'(z_0)\neq0$，则在 $z_0$ 的某个小邻域内 $f$ 单叶，并且存在**解析**的反函数（解析反函数定理）。反过来，单叶解析函数在全定义域上自动处处 $f'(z)\neq0$（否则在 $z_0$ 附近 $f$ 会呈 $m\ge2$ 对 1 的"折叠"，就粘点了）。
- **注意**：$f'\neq0$ 只保证**局部**单叶（局部可掉头）；**全局**单叶是强得多的条件，二者不能混。

## 五、多值性是"怎么来的"：限制定义域、选分支

多值函数几乎都是"不单叶的单值函数反过来看"的产物：

| 正向函数 | 在哪里不单叶 | 反向的多值 | 限制到单叶区域后的单值分支 |
| --- | --- | --- | --- |
| $w=z^2$ | 全平面（$\pm z$ 粘点） | $\sqrt{w}$（两值） | 限制 $\operatorname{Re}z>0$ → 主支 $\sqrt{w}$ |
| $w=z^n$ | 全平面（差 $2\pi/n$ 转角的点粘点） | $\sqrt[n]{w}$（$n$ 值） | 限制到 $2\pi/n$ 的扇形 |
| $w=e^z$ | 全平面（差 $2\pi ik$ 粘点） | $\log w$（无穷多值） | 限制到 $(-\pi,\pi)$ 水平条 → 主支 $\operatorname{Log}$ |

再用解析延拓的眼光看：沿着一条绕过"机关点"的闭路走一圈回来，分支可能回不到原样（$\sqrt{w}$ 换号、$\log w$ 加 $2\pi i$）。制造这种"绕一圈就换层"的点叫**支点**（例如 $\sqrt{w}$、$\log w$ 的 $w=0$）；为了把多值拆成单值，人为剪开一条不让绕行的线叫**支割线**；把各层完整铺在一起、让多值函数变成其上的单值函数的那本"多层书"，叫**黎曼面**。这些是后续章节的正片预告。

## 六、常见疑问

- **单值和单叶到底怎么记？** 单值管**前向**（一个输入不许劈叉），单叶管**后向**（两个输入不许合并）。做题先问：现在要判的是哪一头？
- **$f(z)=1/z$ 单叶吗？** 在 $\mathbb{C}\setminus\{0\}$ 上单叶（不同点倒数不同）；在扩充复平面 $\mathbb{C}_\infty$ 上更是完美的双射，把 $0$ 与 $\infty$ 互换——和"无穷远点"那篇笔记的画面接得上。
- **$f(z)=z^3$ 单叶吗？** 在全平面不是：$z$ 与 $ze^{2\pi i/3}$ 被粘到同一点；但限制到任意 $120°$ 扇形（开角 $2\pi/3$）上就单叶了。
- **$f'(z)\neq0$ 就等于单叶吗？** 不等于。它只保证**局部**单叶；整块区域上是否单叶要另外判断。反例：$f(z)=2z+z^2$ 满足 $f'(0)=2\neq0$，但全平面不单叶（$0$ 与 $-2$ 都映到 $0$）。
- **多值函数到底算不算函数？** 严格说不算，它是一种对应关系；考试里说"多值函数"是沿用习惯叫法，真正参与求导、积分的是它的单值分支。

## 七、自测（想不起来就翻上文）

> [!question]- $f(z)=1/z$ 在 $\mathbb{C}\setminus\{0\}$ 上单叶吗？用定义验证一遍。
> 是。设 $z_1\neq z_2$ 且都不为 $0$，若 $\frac{1}{z_1}=\frac{1}{z_2}$，交叉相乘得 $z_1=z_2$，矛盾。所以不同输入给出不同输出，单叶。（顺便：反函数还是它自己。）

> [!question]- 用"粘点 → 掉头劈叉"的语言解释：为什么 $z^2$ 的反关系 $\sqrt{w}$ 是多值的？
> $z$ 与 $-z$ 被粘成同一个 $w=z^2$；掉头看，$w$ 要同时回到 $z$ 与 $-z$ 两处，一个输入两个输出，所以多值。把 $z^2$ 限制到右半平面（只留 $+z$ 那一半）后，不再粘点，掉头才得到单值的主支 $\sqrt{w}$。

> [!question]- $f$ 解析、$f(0)=0$、$f'(0)=2\neq0$。能断定 $f$ 在整个平面上单叶吗？
> 不能。$f'(0)\neq0$ 只保证在 $0$ 附近的小邻域里单叶（局部有解析反函数）；全局单叶需要另外证明。反例：$f(z)=2z+z^2$ 满足条件，但 $f(0)=f(-2)=0$，两个不同点落到同一处，不单叶。

## 八、术语小词典（复习用）

| 术语 | 通俗解释 | 正式一点的说法 |
| --- | --- | --- |
| 单值函数 | 一个输入恰好一个输出，前向不劈叉 | $f:D\to W$，每 $z$ 对应唯一 $w$ |
| 多值函数 | 一个输入对应多个输出；不是严格函数 | 一种对应关系；靠单值分支才能当函数用 |
| 单值分支 | 从多值对应里一致地挑出一条，成为正常函数 | 区域上连续（解析）的单值选择 |
| 单叶 / 单射 | 不同输入必不同输出，后向不合并 | $z_1\neq z_2\Rightarrow f(z_1)\neq f(z_2)$，injective |
| 单值 vs 单叶 | 前向不劈叉 vs 后向不合并 | 互不包含的两个条件 |
| 反函数 | 箭头全部掉头 | $f^{-1}:f(D)\to D$ |
| 解析反函数定理 | 导数不为零 ⇒ 局部可掉头，且反函数解析 | 局部双全纯（局部共形） |
| 单叶解析函数 | 单叶 + 解析（自动处处 $f'\neq0$） | univalent / schlicht function |
| 保角 | 夹角保持不变（解析 + $f'\neq0$） | conformal mapping |
| 支点 | 绕它转一圈会换分支的"机关点" | branch point（如 $\sqrt{w}$、$\log w$ 的 $0$） |
| 支割线 | 为了选分支，人为剪开、禁止绕行的一条线 | branch cut |
| 黎曼面 | 把多值函数的各层铺成一本"多层书" | Riemann surface |
