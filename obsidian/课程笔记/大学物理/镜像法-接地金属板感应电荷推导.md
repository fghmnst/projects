# 镜像法：接地金属板感应电荷推导（新手版）

> 相关：[[课程笔记/大学物理/接地模型-电势锁零与电荷不守恒|接地模型]] · [[课程笔记/大学物理/大学物理|大学物理]]

> [!note] 一句话先行
> 接地金属板上方距离 $d$ 处放一个点电荷 $+q$，板上的感应电荷总量**恰好是 $-q$**。推导的关键不是硬解电荷，而是让电势条件 $U=0$ 当"选拔赛裁判"：**猜**一个等效电荷分布 → 用 $U=0$ 验证 → 唯一性定理担保猜的就是真解 → 电荷从真解里顺手读出来。下面一步步走；遇到生词翻文末「术语小词典」。

## 一、先说清关键逻辑：$U=0$ 是裁判，不是算式

$U=0$ **不能像代数方程那样直接"解出"感应电荷**——板上电荷在哪儿、多少都不知道，方程写不出来。它的真正用法是一条流水线：

```
猜一个电荷分布 → 算它产生的电势 → 过不了 U=0 就淘汰
                → 过了 → 唯一性定理担保：它就是真解
                → 有了真解，感应电荷顺手就能算出来
```

所以"用电势条件推导 $q$"，实际是"用 $U=0$ **筛选并担保**一个解，再从解里读出 $q$"。

## 二、第一步：猜"镜像世界"

板上方距板 $d$ 处有 $+q$。我们**猜**：感应电荷的一切对外效果，等价于板"背后"镜面对称的位置蹲着一个 $-q$——它叫**像电荷**（镜像电荷），注意它不是真实存在的电荷。

为什么敢这么猜？看对称性：把一个 $+q$ 和一个 $-q$ 关于平面对称摆放，它们的**中垂面**天生就是 $U=0$ 的等势面（下一步验证）。所以"+q + 背后镜像 −q"这个组合，恰好造出一块 $U=0$ 的平面——和接地板的要求**长得一模一样**。

## 三、第二步：用 $U=0$ 验证猜测（这就是"使用电势条件"）

在板上任取一点 $P$，设它到垂足的距离为 $r$。关键观察：**$P$ 到 $+q$ 和到镜像 $-q$ 的距离永远相等**（都是 $\sqrt{r^2+d^2}$）。由电势叠加：

$$
U_P = \frac{q}{4\pi\varepsilon_0 \sqrt{r^2+d^2}} + \frac{-q}{4\pi\varepsilon_0 \sqrt{r^2+d^2}} = 0
$$

**不用背的读法**：板上每一点到两个电荷一样近，一个"$+q$ 的份"、一个"$-q$ 的份"，加起来永远清零。这对板上**每一点**都成立，所以整块板处处 $U=0$ ✅——猜测通过选拔赛。

## 四、第三步：唯一性定理盖印章

> **唯一性定理（大白话）**：一块区域里，"内部的电荷分布"给定 + "边界上的电势"给定，那么区域内的电势解**有且只有一个**。

现在"+q 与像电荷"给出的解，和"+q 与真实感应电荷"的真正解，在**板上方的半空间**里满足完全相同的条件（内部的源都是那个 $+q$；边界都是这块 $U=0$ 的平面）。唯一性定理于是宣布：两个解在板上半空间**完全等价**。盖章生效——板外的场、电势，全都可以直接用"+q 与镜像 −q"这套干净的系统来算。

## 五、第四步：从真解里"顺手"读出感应电荷

### 直观版：数电场线（30 秒看懂）

在纯 $+q/−q$ 的世界里，**$+q$ 发出的每一条电场线都终止于 $-q$**，而且每条线都得从上半空间钻到下半空间——也就是说**每条线都必须横穿中垂面**。现在把导电薄板插进这块 $U=0$ 的平面里：电场线落点不变，只是从"穿过去找镜像"变成"**终止在板表面的感应电荷上**"。

电场线条数正比于电量：$+q$ 的全部电场线（对应电量 $+q$）一条不漏全部落板 → **板上感应电荷总量 $=-q$**，没有一条线漏网跑向无穷远（这也和"板外无场"对得上）。

### 严格版：表面积分（展示 $U=0$ 解出的场如何产出 $q$)

镜像解给出：板面上方的场**垂直**砸向板面（切向分量被 $+q/−q$ 对称抵消，法向分量加倍），到垂足距离 $r$ 处的法向场大小为

$$
E_\perp(r) = \frac{qd}{2\pi\varepsilon_0\,(r^2+d^2)^{3/2}}
$$

导体表面电荷密度与场的关系（高斯定律的边界版，场指向板内为负）：$\sigma(r) = -\varepsilon_0 E_\perp(r)$。全板积分：

$$
Q = \int_0^{\infty} \sigma(r)\cdot 2\pi r\,dr = -qd\int_0^{\infty} \frac{r\,dr}{(r^2+d^2)^{3/2}} = -qd\cdot\frac{1}{d} = -q
$$

（那个积分的原函数是 $-\dfrac{1}{\sqrt{r^2+d^2}}$：上极限代 0、下极限代 $d$，相减恰好剩 $\dfrac{1}{d}$，$d$ 正好消掉——答案干净得不像巧合。）

## 六、复盘：$U=0$ 在整个推导里的三重角色

1. **筛选器**：淘汰所有不满足"板面等势且为零"的猜测；
2. **担保人**：配上唯一性定理，保证猜中的解就是唯一真解；
3. **产出来源**：真解给出场分布 → 场给出 $\sigma$ → 积分给出 $-q$。

顺带回答一个自然疑问：**为什么结果和板距 $d$ 无关？** $d$ 变小时 $\sigma$ 分布变"瘦高"，$d$ 变大时变"矮胖"，但曲线下的总面积恒为 $-q$——积分里 $d$ 恰好消去，正是"全部电场线一条不漏落板"的数学写照。

## 七、自测（想不起来就翻上文）

> [!question]- 像电荷 $-q$ 是真实存在的电荷吗？
> 不是。它只是让**板上半空间**的解等价于真实感应电荷的假想电荷；板内部实际没有电场，也不存在这个电荷。像电荷只在板外区域"合法"。

> [!question]- 为什么验证 $U=0$ 时只需"到两电荷距离相等"这一个观察？
> 因为叠加原理下，等距、等量、反号的两电荷在每点电势严格抵消。中垂面上每点到 $+q$ 与 $-q$ 距离恒等，所以整面 $U=0$ 一步到位。

> [!question]- 若板不接地而是绝缘中性，还能用镜像法吗？板上总感应电荷是多少？
> 不能直接用：此时边界条件是"整板 $U=$ 某未知常数"而非 $U=0$，镜像猜法失效。板上总感应电荷为 $0$（近侧 $-q$、远侧 $+q$），这正是接地与不接地的本质差别（见 [[课程笔记/大学物理/接地模型-电势锁零与电荷不守恒|接地模型]] 的对比表）。

> [!question]- 严格版积分结果为何与 $d$ 无关？
> $\sigma$ 的分布形状随 $d$ 变化，但总"面积"恒为 $-q$：$d$ 在积分中恰好消去。几何直觉：$+q$ 的每条电场线都落板，条数不随距离改变。

## 八、术语小词典（复习用）

| 术语 | 通俗解释 | 正式一点的说法 |
| --- | --- | --- |
| 像电荷（镜像电荷） | 假想的电荷，用来"顶替"感应电荷的效果；只对板外区域有效 | image charge，等效替代而非真实电荷 |
| 边界条件 | 解必须在边界上满足的要求；接地 = 边界 $U$ 锁 0 | boundary condition |
| 唯一性定理 | 内部电荷 + 边界电势给定，解有且只有一个；猜中也算数 | 唯一性定理（静电边值问题） |
| 电势叠加 | 每点电势 = 各电荷贡献的代数和；验证 $U=0$ 靠它 | $U_P=\sum_i \frac{q_i}{4\pi\varepsilon_0 r_i}$ |
| $\sigma$（面电荷密度） | 板面上每单位面积摊到的电荷，像场"落地雨量" | $\sigma = \frac{dQ}{dA}$ |
| $\varepsilon_0$ | 真空"存电场"能力的基本常数，让库仑/电势公式成立 | 真空电容率 |
| 高斯定律（边界版） | 导体表面场强与面电荷的换算：$E = \frac{\sigma}{\varepsilon_0}$，方向垂直表面 | $E_n=\frac{\sigma}{\varepsilon_0}$ |
