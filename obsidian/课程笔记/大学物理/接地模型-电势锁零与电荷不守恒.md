# 接地模型：电势锁零与电荷不守恒（新手版）

> 相关：[[课程笔记/大学物理/大学物理|大学物理]] · 推导示范：[[课程笔记/大学物理/镜像法-接地金属板感应电荷推导|镜像法：接地金属板感应电荷推导]]

> [!note] 一句话先行
> 接地的物理本质：**用导线把导体"并进"地球这个巨大导体，合并成一个等势体。** 小导体从此背靠一座"无限深的电荷池"——电势被**锚**死在 0，电荷可以无限量自由进出（**库**）。题设里每个"接地"字样，翻译过来就是这两条：**电势锁 0 + 电荷不再守恒**。下面先建图像，再翻译成解题规则；遇到生词随时翻文末「术语小词典」。

## 一、本质图像：接地 = 把小导体并进地球这个巨大导体

- **导线连接在静电学里只有一层含义：合并成一个导体。** 接上地线后，"你的导体 + 地球"就是同一个等势体，电荷可以在两者之间无阻力流动。
- **这个组合极其不对称，不对称正是它好用的原因。** 算一笔数字账：地球的电容（"装电荷不涨电势"的本事）$C_\text{地}=4\pi\varepsilon_0 R_\text{地}\approx 7\times10^{-4}\,\mathrm{F}$，即约 700 μF；实验室导体的电容只有 pF 量级。合并后小导体对组合体电势的扰动只占 $10^{-9}$ 量级——**组合体的电势就是地球的电势，被钉死在 0**。
- **画面版**：把大地想成一家"无限大的电荷银行"——你往里存 1 库仑或取走 100 库仑，它的"汇率"（电势）纹丝不动，永远记作 0。往太平洋里倒一杯水，水位不见涨。

于是"小导体"自动继承两条性质，它们就是接地的全部：

1. **锚**：电势被钉在 0（组合体等势，而地球部分怎么吞吐都是 0）；
2. **库**：电荷可以自由进出（小导体交出了"电荷自主权"）。

## 二、"只考虑一小部分"为什么合法

把导体和地球看作一个巨大导体后，题目里我们只关心其中的一小部分——这**完全合法**，原因是：巨大伙伴的全部影响可以**浓缩成上面那两句话**（锚 + 库），除此之外它的任何细节都不进方程。

- 地球的曲率、表面电荷怎么摊、远端有什么场——对实验室尺度的影响按 $R_\text{地}$ 的平方、立方衰减，全部可忽略；
- $U=0$ 是**局域边界条件**：它只约束小导体自己表面上的每一点，与地球的形状无关；
- 所以解题时地球从不以几何形态出现，只以"锚 0 + 无限吞吐"这两个身份出场。

## 三、题设说"接地"，翻译成两条解题规则

**规则 1：电势条件 $U = 0$**

这是接地带来的**唯一硬性约束**。题目让你求感应电荷、求场强、求电容……最终都是靠"这个导体电势为 0"列出方程解出来的。

**规则 2：电荷不守恒了（新手最大的坑！）**

| | 未接地 | 接地后 |
| --- | --- | --- |
| "导体带电 Q" 这句话 | Q 保持不变，放心拿来解题 | **作废！** 电荷流进/流出大地，最终带电量必须靠 $U=0$ 重新解出来 |
| 最终电荷的可能取值 | 就是原来的 Q | 任何值都可能：0、正、负 |

> [!warning] 解出负数不要慌
> 方程解出导体最终带 $-q$，只说明电荷是从大地**流上来**的——银行不但没收走你的钱，反而支付了一笔。符号本身就是计算结果的一部分。

## 四、一个经典对比：点电荷旁的金属板

点电荷 $+q$ 附近放一块金属板，两种情形结果完全不同：

| 情形 | 板上总感应电荷 | 板背面/板外有场吗 |
| --- | --- | --- |
| 绝缘中性板（不接地） | $0$（近侧感应出 $-q$，远侧 $+q$，正好抵消） | 有 |
| **接地板** | $-q$（远侧的 $+q$ 被大地"吸走"，又从近处补来 $-q$） | 无 |

注意反直觉的一点：接地**没有让板上电荷消失，反而吸来了更多**。因为"电势为 0"是唯一目标，银行为达成它愿意任意支付电荷。这个例子的完整推导（怎么从 $U=0$ 一步步算出 $-q$）单独开了一篇：[[课程笔记/大学物理/镜像法-接地金属板感应电荷推导|镜像法：接地金属板感应电荷推导]]。

## 五、关键警告："一小部分" ≠ "一小份电荷"

"小导体只占巨大导体的一小部分"，说的是**体积份额**，千万别理解成**电荷份额**。导体上的电荷密度由**局域条件**决定（表面曲率、附近外场、$U=0$ 约束），与它占组合体的比例无关：

| 情形 | 小导体拿到的电荷 | 为什么 |
| --- | --- | --- |
| 孤立双球导线相连（无外场） | 确实只占 $R_\text{小}/R_\text{大}$ 的比例，少得可怜 | 电势相同 $\Rightarrow q\propto R$ |
| 小接地物体靠近带电体 $+q$ | 感应电荷可以**相当可观** | 由局域 $U=0$ 解出，地球只管"锚 0 + 吞吐" |

镜像法那篇就是现成例子：接地板吸来的 $-q$ 完全由局域电势条件算出；流上地球的 $+q$ 摊在 6400 km 的表面上，局域密度≈0，但它在"账本上"真实存在——这正是库的作用。

## 六、"不用背"的读法

- 看到题设"接地" → 脑内自动翻译成：**"这儿的电势锁 0，电荷随便借还"**。
- 解题顺序永远是：**先放弃原电荷守恒 → 写 $U=0$ 方程 → 解出最终电荷**；地球的几何永远不出现在式子里。
- 容易混的近亲：
  - "导体**不带电**" ≠ "导体**接地**"：前者约束电荷（$Q=0$），后者约束电势（$U=0$），是两条不同的条件。
  - 接地后导体叫"电势确定、电荷待定"；孤立导体叫"电荷确定、电势待定"。

## 七、自测（想不起来就翻上文）

> [!question]- 小部分（接上地的导体）的电势是"恰好 0"还是"接近 0"？
> 理想模型里恰好 0（把地球电容取作无穷大）。实际情况偏离 0 只有 $10^{-9}$ 量级，被理想化抹掉——所以方程里写"="不写"≈"。

> [!question]- 接地导体最终一定不带电吗？
> 不一定。带电量由 $U=0$ 决定，可以是 0、正或负。例如点电荷旁的接地板感应出总量 $-q$，反而"吸来"了电荷。

> [!question]- 内球带 $+q$、同心外球壳接地，球壳外表面带电多少？壳外有场吗？
> 外表面带电 $0$，壳外无电场。推导思路：壳内表面感应 $-q$（由高斯定律保证内腔场），若外表面还有电荷，壳外就有场、壳电势就不为 0，与接地矛盾；所以外表面电荷被大地"吸走"，壳外场消失。

> [!question]- 接地小物体的感应电荷一定很少吗（它只是巨大导体的一小部分）？
> 不一定。"一小部分"是体积份额，不是电荷份额。附近有带电体时，感应电荷由局域 $U=0$ 解出，可以相当可观——电荷密度由局域曲率与外场决定，不按大小比例分配。

> [!question]- "q ∝ R"（双球导线相连时小球只拿一点点电荷）什么时候能用？
> 只在**无外场**、两球都近似孤立时成立（电势相同逼出 $q\propto R$）。一旦附近有带电体，外场会往小球上"压"电荷，比例思维作废。

## 八、术语小词典（复习用）

| 术语 | 通俗解释 | 正式一点的说法 |
| --- | --- | --- |
| 等势体 | 连成一体的导体内部/表面电势处处相同，电荷可无阻力流动 | 静电平衡导体的性质 |
| 电势 $U$ | 单位电荷在那儿的"能量海拔"，接地 = 海拔钉在 0 | 电势：单位电荷的电势能，$U=\frac{E_p}{q}$ |
| 大地 | 电容无穷大的导体，电荷吞吐不改变其电势，约定 $U_\text{地}=0$ | 零电势参考点（理想化模型） |
| 接地 | 用导线把导体并进地球这个巨大导体：电势锁 0、电荷可流动 | 导体与大地等势，$U=0$ |
| 电容 | 一个导体"装电荷不涨电势"的本事；地球约 700 μF，实验室导体 pF 级 | $C=\frac{Q}{U}$，孤立球 $C=4\pi\varepsilon_0 R$ |
| 感应电荷 | 外部电荷"隔空搬运"到导体表面的电荷 | 静电感应产生的表面电荷 |
| 电荷密度 / 曲率 | 电荷爱挤在尖（曲率大）的地方；小物体局域密度可以很高 | 曲率半径越小面电荷密度越大 |
| 局域边界条件 | $U=0$ 只约束小导体自己表面上的每一点，与地球形状无关 | 边界条件（静电边值问题） |
| 电势叠加 | 每点电势 = 所有电荷贡献的代数和；接地体的 $U=0$ 就是靠它列方程 | $U_P=\sum_i \frac{q_i}{4\pi\varepsilon_0 r_i}$ |
| 孤立导体 | 不接地、与外界断开电荷往来的导体：电荷守恒、电势待定 | 电荷给定、电势由分布决定 |
