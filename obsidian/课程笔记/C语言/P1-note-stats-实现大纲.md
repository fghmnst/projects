# P1 `note-stats` 实现大纲（W3-W4）

> [!note] 一句话先行
> `note-stats` 是一个"笔记库体检器"：喂它一个目录，它把底下所有 `.md` 数一遍——几个文件、几行、几个字。
> **分工**：本大纲由 AI 编写（目标 / API 速查 / 算法步骤 / 验收标准 / 坑）；`C-tools/note-stats/` 下的每一行代码由你亲手写。卡壳随时来问，但不代写全部答案。

## 〇、验收目标（写之前先知道"做到什么算完"）

- 入口：`./note-stats <目录>`
- v0.1 输出：
  - 每个 `.md` 一行：字数、行数、路径
  - 末尾汇总：文件数 / 行数 / 字数
- 错误处理：目录打不开 → stderr 报错 + 非 0 退出码；单个文件打不开 → 报错后跳过，不中断
- W4 轻门标准：**可运行、可演示**——不要求排序、彩色、命令行选项
- 对账基准（2026-09-22 实测；日志天天改，数字会涨，以你跑命令当天的为准）：

| 指标 | 对账命令 | 2026-09-22 的值 |
| --- | --- | --- |
| `.md` 文件数 | `find obsidian -name '*.md' \| wc -l` | 107 |
| 总字符 | `find obsidian -name '*.md' -exec wc -m {} + \| tail -1` | 297523 |
| 总行数 | `find obsidian -name '*.md' -exec wc -l {} + \| tail -1` | 8551 |

- **范围纪律（W3-W4 明确不做）**：动态内存 `malloc`（P2 才学）、排序、彩色输出、`--tag` 之类的选项、大写 `.MD`、符号链接特殊处理。

## 一、地图：程序长什么样

- 文件：`C-tools/note-stats/Makefile` + `note-stats.c`（单文件，不拆模块）
- 数据流：

```
argv[1]（目录路径）
   │
   ▼
scan_dir：遍历目录 ──► 遇到子目录 → 再调用自己（递归）
   │
   └──► 遇到 .md 文件 → analyze_file：逐字节统计

                                ▼
                         累加进 Totals → main 末尾打印汇总
```

- 建议函数清单（名字随你改；**这里只给职责，不给实现**）：

| 建议签名 | 职责 |
| --- | --- |

## 二、步骤 1：Makefile（约 1h）

**目标**：`make` 一条命令完成编译，`make clean` 清理。

你要写的三块：
1. **变量**：编译器用 `gcc`；编译参数要含 `-Wall -Wextra -std=c17 -g`
2. **主规则**：目标名 `note-stats`、依赖 `note-stats.c`、命令里用变量展开
3. **clean 规则**：删掉可执行文件；并声明 `clean` 是"伪目标"（不是文件名）

参数逐项解释：

| 参数 | 作用 |
| --- | --- |
| `-Wall -Wextra` | 让编译器把所有可疑写法都喊出来（警告不是错，但先清零） |
| `-std=c17` | 指定用哪一年的 C 方言，避免"默认方言"漂移 |
| `-g` | 带上调试信息（以后用 gdb 要看它） |

坑：
- **命令行首必须是 Tab 键**，空格会报 `missing separator`；这是 Makefile 最著名的坑
- `make` 默认执行第一个目标，所以主规则要放在最前
- `.PHONY: clean` 告诉 make"clean 是动作不是文件"，避免目录里恰好有同名文件时行为怪异

验收：

```bash
cd C-tools/note-stats
make            # 编译通过，零警告
./note-stats     # 应打印用法提示；echo $? 得 1
ls note-stats    # 二进制在（.gitignore 已排除它，不会误提交）
make clean       # 二进制消失
```

提交：`feat: note-stats 加 Makefile，编译闭环`

## 三、步骤 2：递归遍历（约 1.5h）

**目标**：`./note-stats obsidian` 能把 107 个 `.md` 路径全部列出来（先不统计），数量与 `find` 对账。

本步新 API 速查：

| API | 头文件 | 一句话 |
| --- | --- | --- |
| `DIR *opendir(const char *name)` | `<dirent.h>` | 打开"目录流"（一叠牌的把手）；失败返回 NULL |
| `struct dirent *readdir(DIR *d)` | 同上 | 抽下一张牌；抽完返回 NULL |
| `int closedir(DIR *d)` | 同上 | 收牌 |
| `entry->d_name` | 同上 | 牌上的名字——**只有文件名，没有路径** |
| `int stat(const char *path, struct stat *buf)` | `<sys/stat.h>` | 查路径的"档案"：类型、大小、修改时间 |
| `S_ISDIR(st.st_mode)` / `S_ISREG(...)` | 同上 | 读档案类型栏：是目录吗 / 是普通文件吗 |
| `int snprintf(char *dst, size_t n, const char *fmt, ...)` | `<stdio.h>` | 安全拼字符串：最多写 n-1 个字符，返回"本来想写多长" |
| `int strcmp(a, b)` | `<string.h>` | 比内容（`==` 比地址的坑你已写过笔记） |
| `void perror(const char *msg)` | `<stdio.h>` | 打印 `msg: 具体错误原因`（已学） |

算法步骤（**按这个顺序写，调试面最小**）：
1. `opendir` 打开目录；返回 NULL → `perror` + 返回失败
2. `while ((entry = readdir(dir)) != NULL)` 逐张抽牌
3. **先跳过 `.` 和 `..`**——否则递归绕回自己，无限套娃
4. `snprintf` 拼出完整路径 `目录/文件名`；检查返回值是否 ≥ 缓冲区大小（说明被截断，报错跳过）
5. `stat` 查档案；失败 → `perror` + 跳过（一个坏的不能毁全盘）
6. 是目录 → **递归**：调用自己，把同一个总账指针传下去
7. 是普通文件且以 `.md` 结尾 → `printf` 路径（本步先不统计）
8. `closedir` 收尾——**每一层都要收**

两个设计说明：
- 后缀判断建议 `strlen` + `strcmp` 比末尾 3 个字符；不要用 `strstr`（会把 `a.md.txt` 误判成 md）
- 类型判断建议用 `stat` 而不是 `entry->d_type`：`d_type` 在部分文件系统会返回"不知道"，而 `stat` 永远可靠，且步骤 5 的"近期改动"反正要用它

坑：路径缓冲区开大一点（比如 1024）——本仓库中文长路径不少；调试时允许先打印**所有**条目名，确认遍历对了再加 `.md` 过滤。

验收：

```bash
cd C-tools/note-stats
make
./note-stats ../../obsidian | wc -l    # 预期 107
./note-stats ../../obsidian | head -5  # 肉眼抽查几条路径确实存在
```

提交：`feat: note-stats 递归遍历目录，列出 .md`

## 四、步骤 3：统计行数与字数（约 1.5-2h）

**目标**：每行输出「字数 行数 路径」，末尾总计；总字数 / 总行数与 `wc` 对账。

本步新 API：

| API | 一句话 |
| --- | --- |
| `FILE *fopen(path, "r")` | 拿文件的"取号牌"；失败返回 NULL |
| `char *fgets(buf, size, fp)` | 读一行进缓冲区（含换行符）；读到结尾返回 NULL |
| `int fclose(FILE *fp)` | 还牌 |
| `int fgetc(FILE *fp)` | 备选：一次读 1 个字节，结尾返回 EOF |

**两条计数口径**（先定口径再写代码，这是工程习惯）：
- **行数 = 换行符 `'\n'` 的个数**——和 `wc -l` 同口径；最后一行如果没有换行符就不算（这是口径，不是 bug）
- **字数 = "不是续字节的字节"个数**——和 `wc -m` 同口径

UTF-8 速成（为什么不能直接数字节）：

```
英文 1 字节： 0xxxxxxx
2 字节字符：  110xxxxx 10xxxxxx
汉字 3 字节： 1110xxxx 10xxxxxx 10xxxxxx
```

规律：多字节字符的**后续字节都以 `10` 开头**。所以"一个字符只数一次"＝只数**不是续字节**的字节。
判断公式（这是编码事实，直接用；项目核心逻辑仍然是你写）：`(byte & 0xC0) != 0x80` → 是首字节，计数。
`& 0xC0` 的意思是"只保留最高两位"，把 `10` 开头（其实是 `0x80`–`0xBF`）的续字节筛掉。

主循环建议（伪代码；具体代码你写）：

```
打开文件 → 失败则 perror + 返回错误
while (读进一行) {
    对这一行的每个字节：
        是 '\n' → 行数 + 1
        不是续字节 → 字数 + 1
}
关闭文件
```

坑：
- 一个文件打不开 → 报错后 **continue**，不要退出整个程序
- `fopen` 必须配对 `fclose`
- 缓冲区 4096 够用；超长行会被 `fgets` 拆成多次读，跨次累计照样对（也是为什么行数要数 `'\n'` 而不是数读取次数）
- 打印 `long` 用 `%ld`；比较字节前把 `char` 转成 `unsigned char`（负数参与位运算容易出妖）
- 中文路径读/打印没问题，Linux 路径本来就是字节

验收：

```bash
cd C-tools/note-stats
./note-stats ../../obsidian | tail -1
find ../../obsidian -name '*.md' -exec wc -m {} + | tail -1   # 297523
find ../../obsidian -name '*.md' -exec wc -l {} + | tail -1   # 8551
```

数字允许小幅漂移（日志还在改）；原则：同一批文件、同一条命令应完全一致，有差异要能解释。

提交：`feat: note-stats 统计 .md 行数与 UTF-8 字数（对齐 wc -m 基准）`

## 五、步骤 4：结构体封装（约 1h）

**目标**：把散落的计数变量收进"档案卡"，把统计逻辑抽成函数；**行为零变化**。

两张档案卡（建议字段，名字随你）：

| 结构体 | 字段 | 装什么 |
| --- | --- | --- |
| `FileStats` | `long lines; long chars;` | 单个文件的行数、字数 |
| `Totals` | `long files; long lines; long chars;` | 全局累计 |

要点：
- 用 `typedef struct { ... } 名字;` 给结构体起外号
- 统计函数收 `FileStats *out`，通过 `out->lines` 填写
- 遍历函数收 `Totals *tot`；递归时一路传**同一个指针**，让所有层往同一张总账上记

新术语见文末词典；本步完成后 `main` 应该变得很短，脏活都在两个函数里。

验收：
- 输出与步骤 3 **一字不差**（重构不改行为；行为变了说明引入了 bug）
- `git diff` 呈"搬家式"改动：新增函数、`main` 变短

提交：`refactor: note-stats 结构体封装与函数拆分`

## 六、步骤 5（选做，周五 9/25 放假）：标题 / 标签 / 近期改动（约 2h）

做不完不算失败——W4 门只要求前四步"可演示"。

- **标题树**：逐行看，跳过行首空格后第一个字符是 `#` 的话，数连续 `#` 的个数 = 层级；输出形式自定（各级数量统计 / 缩进打印）
- **标签**：找 `#` 后紧跟字母或汉字的组合；**前一个字符是 `#` 的不算**（排除标题）；已知粗糙点：代码块里的 `#` 也会被算——P1 允许粗糙，把口径写进输出或注释即可
- **近期改动**：`stat()` 你在步骤 2 就用了；`st_mtime` 字段 = 最后修改时间；`time_t` 是"从 1970 年 1 月 1 日起的秒数"；`time(NULL)` 拿"现在"，两者相减小于 `7*24*3600` 就算 7 天内改过

验收：在 `obsidian/每日日志` 下跑，9/16–9/22 的日志应出现在"近期"结果里。

提交：`feat: note-stats 标题树/标签/近期改动`

## 七、坑总表（动手前扫一眼）

| 坑 | 症状 | 正解 |
| --- | --- | --- |
| Makefile 命令行首用空格 | `missing separator` | 必须是 Tab |
| `==` 比字符串 | 永远不相等（比的是地址） | `strcmp(...) == 0` |
| 忘了拼路径 | open 失败 / 统计不到 | `readdir` 只给名字，要 `snprintf` 拼 |
| 不跳 `.` / `..` | 递归无限转圈 | 循环里先 `continue` |
| 递归不 `closedir` | 目录句柄泄漏 | 每条路径收尾 |
| 直接数字节 | 中文多算 2 倍 | 数"非续字节" |
| `char` 带符号做位运算 | 个别字符判错 | 转 `unsigned char` |
| `fopen` 失败就 `return` | 一个坏文件中断全盘 | `perror` + 跳过 |
| 手痒想加 malloc / 排序 / 选项 | 范围失控、进度黑洞 | 全推后（P2 再上） |
| 卡壳硬扛超过 20 分钟 | 时间黑洞 | `printf` 打桩 + 来问 |

## 八、调试协议

1. **先清警告**：`-Wall -Wextra` 报的都先处理，警告清零再跑
2. **printf 打桩**：在每个函数入口打印参数，确认"走到哪一步、参数对不对"

## 术语小词典

| 术语 | 大白话 |
| --- | --- |
| Makefile / 目标 / 依赖 | 编译菜谱；"目标"是要做出来的菜（可执行文件），"依赖"是食材（源文件） |
| 伪目标（`.PHONY`） | 不是文件、只是动作的名字（如 clean），提醒 make 别去找同名文件 |
| 目录流（`DIR *`） | 一叠牌的把手；`opendir` 打开、`readdir` 抽牌、`closedir` 收牌 |
| 目录项（`struct dirent`） | 抽到的"一张牌"：一个文件名（或子目录名）的信息 |
| 递归 | 函数自己叫自己；转包里还有转包，遇子目录就再来一轮 |
| 缓冲区 | 提前开好的一块数组空间，用来暂存读进来的内容 |
| `snprintf` | 安全的字符串拼接：给你一个长度上限，超了就截断并告诉你 |
| `FILE *` | 文件的"取号牌"；拿着它才能读/写，用完必须还（`fclose`） |
| EOF | End Of File，文件末尾的暗号 |
| UTF-8 / 续字节 | 把每个字编成 1–3 个字节的编码；多字节字符的后继字节都以 `10` 开头 |
| 位与（`&`） | 二进制"对位相乘"的筛子；`& 0xC0` = 只留最高两位 |
| 结构体 / `typedef` | 一张印好栏目（行数/字数）的档案卡；`typedef` 是给这张卡起外号 |
| 指针传参 / `->` | 把档案卡递给函数让它当场填；`->` 是"走到卡前填某栏" |
| `const char *` | 承诺"只读不改"这个字符串 |
| `static`（函数） | 这个函数只在本文件里用；单文件程序里的好习惯 |
| `stat` / 档案 | 查一个路径的元信息：是文件还是目录、多大、何时改过 |
| `mtime` / `time_t` | 最后修改时间；`time_t` 是从 1970 年起算的秒数 |
| 系统调用 | 程序请求操作系统干活的接口（如 open/read/stat） |
| 重构 | 行为不变，只把代码摆整齐 |

> [!question]- 自测（先自己答，再点开对）
> 1. Makefile 命令行首为什么必须是 Tab？
>    —— make 用"是不是 Tab 开头"区分"命令行"和普通内容；空格会被当成别的语法，报 `missing separator`。
> 2. `(byte & 0xC0) != 0x80` 在筛什么？
>    —— 把最高两位掩出来；不是 `10` 开头的就是"新字符的首字节"（汉字首字节是 `1110...`）。
> 3. 为什么 `readdir` 给出的名字不能直接 `fopen`？
>    —— 它只有文件名，没有目录路径；要先 `snprintf` 拼成 `目录/文件名`。
> 4. 行数为什么不数"读了几次 fgets"？
>    —— 超长行会被拆成多次读取，次数会多算；数 `'\n'` 才和 `wc -l` 同口径。
> 5. `fopen` 失败为什么"跳过"而不是 `return`？
>    —— 一个坏文件不该让整次统计失败；报错记录、继续别的文件。
> 6. 重构后行为应该有什么变化？
>    —— 零变化；行为变了说明重构引入了 bug。
