## 四、自学线设计

### C（W1-10，主粮）

- 资源：K&R《C程序设计语言》当工具书 + 翁恺 C 网课查漏；每周编码 4-5h
- 项目阶梯（纯 C + Makefile + git；拒绝刷题，验收 = 可运行可演示）：
  - **P1（W2-4）`note-stats`**：笔记库统计器（读 .md，统计字数/标签/标题树/近期改动）→ 文件 IO、字符串、指针、结构体
  - **P2（W5-7）`prob-cli`**：描述性统计工具（读 CSV，均值/方差/协方差/简单回归）→ 动态内存、二级指针、参数解析
  - **P3（W8-10）`mytool`**：合并为 git 式子命令工具集（函数指针表分发 + 公共代码重构）
- 代码位置：`C-tools/`
- 每个 P 的"最小可跑版"在阶段末周末交付；范围纪律：不许完美主义拖成黑洞

### 电路（W2-16，自学预习线）

- 定位：下学期才有电路正课，本学期先自学一遍；同时给模电深学轨和云台硬件打地基
- 资源：于歆杰《电路原理》（清华，B站/学堂在线/中国大学MOOC，主线）＋ 邱关源《电路》第 6 版（习题主体，大概率下学期教材）＋ Falstad 仿真（falstad.com/circuit，每章搭小电路）
- 补丁：石群《电路》B站（卡壳章节点播，不整看）；偏好严格跟书可换西交罗先觉 MOOC；MIT 6.002 留寒假有余力再碰
- 节奏：周中 1h 看课 + 周末 1.5h 做题/仿真；做题限时 40min，每章 5-8 题封顶，不追慕课 100% 完成度
- 里程碑（对照阶段门）：W4 Ch1-2 元件/KCL/KVL/等效变换（与模电 W1-4 速览互认）→ W7 Ch3-4 节点回路法与电路定理 → W10 Ch5-7 运放电阻电路/储能元件/一阶二阶时域 → W13 Ch8 相量法（复变刚结课）→ W16 Ch9 正弦稳态（能到哪算哪）
- 降级：W13-15 降 1h/周只保视频；W17-18 暂停保期末
- 笔记落点：`obsidian/课程笔记/电路/电路.md`

### STM32 云台 2.0（W11-16）

- 定位：暑假火控云台的**工程化重构**，把 demo 升级为"中断驱动的多模块工程"
- 目标架构（相对暑假 main.c 的差距清单）：UART 接收中断/DMA、环形缓冲、帧协议（帧头+长度+校验）、periph/app 分层、斜坡/限幅
- 里程碑：W12 中断+协议串口回环 → W13 手感（斜坡/限幅）→ W15 视觉追球闭环 → W16 全系统验收
- 代码位置：`gimbal2/`（平铺 CMake 工程，仿 DDM_test 结构）
- 硬件：USB 摄像头（¥40-70，W11 前购）；云台结构升级（金属齿舵机/支架）W11 定稿
- **视觉方案选型**：W11 启动周决策，不沿用已否定的 HSV 快照方案（见 [[somezhishi/项目笔记/视觉目标追踪方案对比]]）；候选含限位校准+像素-角度映射路线
